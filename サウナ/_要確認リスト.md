## A. 最優先（運営に直結）

- [ ] **プラン価格**：平日・土日祝の各3時間プランの正式価格（CHILLNN実値）
- [ ] **SNS運用の全体像**：使っているSNS（IG/X/TikTok/YouTube/LINE）・投稿頻度・トーン・ハッシュタグ
- [ ] **ブランド文体／顧客対応テンプレ**：返信やSNSの文章トーン、定型文の有無

## B. 売上・経理

- [ ] 月次決算プロセス・税務処理の流れ
- [ ] 銀行口座・経費精算の仕組み
- [ ] 株式会社光和工業の経理との関係（サウナ単体か全社合算か）

## C. 運営ルールの確定（前任AIの推測 → 要承認）

- [ ] 「日曜デフォルトは営業（予定があれば閉店）」で合っているか
- [ ] 「非標準スロット（15–18等）は重なる標準枠を全部売止」で合っているか
- [ ] カレンダーの description はどこまで手動補完するか

- [ ] SNS運用は具体的に何を、どの頻度で？
