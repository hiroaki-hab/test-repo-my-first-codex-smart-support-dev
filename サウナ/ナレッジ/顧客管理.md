## 自動同期の仕組み

- 予約が発生すると **Apps Script Webhook** が自動で3シートに記録する
- 自動管理されている行は**薄緑背景**で識別される

## 🔔 最重要ルール：人間の手書き行は不可侵

- 佐藤様が手書きで追記した行は **絶対に上書き・削除しない**
- 判定は Apps Script の `isAutoManagedId()` が行う：
  - **自動管理ID** = CHILLNN形式（10桁英数字）／または `MANUAL- / TORIDORI- / SB- / PHONE- / KOWA-` プレフィックス
  - **それ以外＝手書き行** → 一切触らない（人間優先の原則）
