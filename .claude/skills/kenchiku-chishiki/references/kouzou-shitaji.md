# 構造・下地・開口

## 1. 「この壁は抜けるか」の判断（木造）

**抜いてよい＝非耐力壁（間仕切壁）／抜けない＝耐力壁・通し柱・筋交いの入った壁**

判別の順序：
1. **図面（軸組図・壁量計算書）を見る**のが最優先。無ければ確認申請図・完了検査済証を探す
2. 現地：**柱は910mm（1間＝1820mm）ピッチ**、間柱は455mmピッチ。下地探しで**厚い柱（105/120mm角）があれば柱**
3. 筋交いの有無は**壁を一部開口して確認**（下地センサー・打診では確実に分からない）
4. 🔴 **2階の荷重を受けている壁（上に梁・柱がある）は抜けない**。抜くなら梁の補強が必要

- 抜く場合の代替：**下がり壁を残す／梁で受ける（LVL・鋼製）／耐力壁を別の位置に振り替える**
- 🔴 **耐力壁のバランス（4分割法）**が崩れると、壁量が足りていても地震時にねじれる。抜いた分は同じ辺に補う
- **2025年4月改正で、木造2階建ての「大規模の修繕」は確認申請が必要**（→ `houki.md`）。壁を大量に触る計画は申請要否を先に判定する

## 2. マンション（区分所有）の制限 🔴

| 部位 | 区分 | 触れるか |
|---|---|---|
| 戸境壁・床スラブ・柱・梁 | **共用部** | ❌ 一切触れない |
| サッシ・玄関ドア（本体） | **共用部** | ❌ 交換不可（内窓・ドア内側の塗装はOK） |
| バルコニー | **共用部（専用使用権）** | ❌ 防水改修は管理組合 |
| PS（パイプスペース）内の共用縦管 | **共用部** | ❌ 枝管の接続位置は要確認 |
| 玄関ドアの内側・室内建具・内装・住設 | **専有部** | ⭕ |

- 🔴 **管理規約と使用細則を必ず読む**。床の遮音等級（**LL-45／L-45以上**の指定が多い）でフローリング材が縛られる
- 工事時間・搬入経路・EV養生・休日作業可否も規約。**申請書を管理組合へ提出→承認が要る**（承認に2週間〜1ヶ月＝工程に効く）
- 上下階・両隣への挨拶は必須。騒音工事（斫り・解体）の日程は事前告知

## 3. 床

- 在来工法：**根太（45角@303/455）→大引（90角@910）→束**。剛床（**構造用合板24〜28mm直張り**）は根太レス
- **床のたわみ・沈み**＝根太のスパン過大／束の沈下／シロアリ・腐朽。原因を特定せず上張りすると再発
- **上張り（重ね張り）**：既存の上に12mm程度の床材を張る。工期短・安価だが
  - 🔴 **段差が12mm出る**（敷居・下枠との取合い、建具の下端カット、ドアの開閉確認）
  - 🔴 **サッシ下枠が埋まる**と水返しが効かなくなる
  - 🔴 **既存が沈んでいる場合は上張りで隠れない**（下地から直す）
- 水回りの床：**耐水合板＋CF／フロアタイル**。洗面・トイレはCFが標準

## 4. 壁・天井の下地

- 石膏ボード（PB）**12.5mm**が標準、天井は9.5mmも。**準耐火・防火では厚み・張り方が規定**される
- 下地ピッチ：間柱455／野縁303〜455
- 🔴 **重量物（手摺・TVボード・吊戸棚・タオル掛け）を付ける所は下地補強**を先に。ボードアンカーだけは脱落する
  - 手摺：**貫（合板12mm以上）を壁内に入れる**。介護保険住宅改修でも要求
- 既存クロス下地の**アク・ヤニ・カビ**はシーラー処理をしないと再発する
- 石膏ボードの継目（ジョイント）にクラック → **パテ・ファイバーテープ**、下地の動きが原因なら根本対処

## 5. 断熱・気密との関係

- 壁を開けたら**断熱材の状態を確認**（グラスウールの落下・濡れ・カビ）。開けた時が入れ替えの好機
- → 詳細は `bousui-dannetsu.md`
