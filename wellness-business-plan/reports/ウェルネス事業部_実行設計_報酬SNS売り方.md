# ウェルネス事業部 事業計画書（詳細版 v3）

（第I部：事業計画本体は別紙 v2 と同一。以下は第II部 実行設計）

## A. 給与・報酬設計（基本給＋歩合）

### 冒頭回答：「売上が読めないから給与を決められない」への結論

**「読めないからこそ、固定給は"生活が回る水準"でフル保証し、上振れは"貢献利益（粗利）連動の歩合"で払う」** のが答えです。売上予測に給与を賭けるのではなく、リスクを人件費（固定費）に転嫁しない構造にします。具体的には次の3層で組みます。

1. **固定基本給（月26〜28万／年312〜336万）を立上げ12ヶ月フル保証**（歩合との相殺なし・クローバック対象外＝実質の最低保証）
2. **貢献利益連動の歩合を、基本給の上に純粋加算**（売上でなく粗利に紐付け、サービス別に率を変える）
3. **初期行動・成果のマイルストン一時金（合計最大約36万）**

これにより、小林氏は「売れなくても生活は守られる」、会社は「売れた分（粗利）からしか歩合を払わない＝固定費が膨らまない」を両立できます。

### A-1. 報酬設計の6原則

| # | 原則 | 狙い |
|---|------|------|
| 1 | 生活が回る固定給を土台にする | 立上げ期の歩合過多＝「読めない売上→生活不安→離職」を防ぐ。年1は基本給フル保証 |
| 2 | 歩合は売上でなく**貢献利益（粗利）**に連動 | 値引き乱発・薄利受注・無料入口の数字化を構造的に抑制し、黒字化（粗利で固定費600万回収）と方向を揃える |
| 3 | 継続（LTV）を最優先で報いる | 主力は月額顧問の継続。13ヶ月目以降の継続粗利に加算率を設ける |
| 4 | 保険は率を最低＋上限＋既存顧問限定 | 元アクサの中立性が最大の差別化。保険で稼げる設計にすると差別化が崩壊するため「稼ぎすぎない」キャップをかける |
| 5 | 行動と成果を分けて評価 | 読めない期はマイルストンで初期行動を促しつつ、一時金の重みは成果（顧問成約数）側に置く |
| 6 | 報酬総額は自己資金化の範囲に収める | 歩合は粗利連動＝売れた分だけ払う。強気シナリオでも粗利がコストを先に生む |

### A-3. 歩合（サービス別・貢献利益ベース）

**共通ルール**：歩合の対象は各サービスの**貢献利益（粗利）**。値引き・原価が乗るほど歩合原資が減る＝薄利受注を自制する設計。全歩合は年1では基本給に**上乗せ（相殺しない）**。

| サービス | 歩合率 | 補足・狙い |
|----------|--------|-----------|
| **月額顧問（主力・継続）** | 月次貢献利益の**15%**（契約1〜12ヶ月目）／**20%**（13ヶ月目以降の継続分） | 初月分析10万分の粗利も同率対象。解約防止・LTV重視で継続に加算。例：1社＝年商60万・粗利45万→初年度歩合約6.8万、継続年は約9万／社 |
| **健康経営セミナー** | 貢献利益の**10%** | 単発乱発を防ぐため率は低め。**＋転換ボーナス5万/社**（参加企業が90日以内に顧問契約に至った場合）で入口→本業の接続を評価 |
| **睡眠測定＋サウナ体験会（入口商材）** | 貢献利益の**8%** | 無料開催は歩合0だが活動マイルストンでカウント。入口は率を抑え、下流の顧問転換で回収 |
| **保険（再登録完了後・従）** | 会社取り分粗利の**5%のみ** | (a) 既存顧問先へのクロスセル限定（新規飛び込み保険営業は対象外）、(b) **年間の保険歩合合計 ≦ 年間の顧問歩合合計のシーリング**。率とキャップの二重で保険偏重を構造防止。コンサル料とは会計・契約とも完全分離 |

**クローバック（戻入）条項**：顧問の初年度中途解約、または保険の13ヶ月以内失効時は既払歩合を戻入。短期の見せかけ成約を防止。

### A-4. 立上げ期の保証給（ドローは非推奨・代替案として提示）

**第一選択＝保証給＋マイルストン一時金方式**

1. **保証給**：立上げ12ヶ月は基本給 月26〜28万（年312〜336万）を全額固定支給。歩合との相殺・クローバック対象外（＝実質最低保証）。歩合はこの上に純粋加算。
2. **マイルストン一時金（初期行動＋成果、合計最大約36万）**

| マイルストン | 一時金 | 性質 |
|--------------|--------|------|
| 体験会／セミナー初回開催 | 3万 | 行動KPI（薄め） |
| 睡眠測定 累計50件 | 3万 | 行動KPI（薄め） |
| 顧問成約 1社目 | 5万 | 成果 |
| 顧問成約 3社目 | 10万 | 成果 |
| 顧問成約 6社目 | 15万 | 成果（厚め） |

→ 行動KPIは薄く、成果（顧問社数）側を厚く配分し空回り活動を防ぐ。

3. **代替案（本人が上振れ狙いを明確に希望する場合のみ）＝半回収ドロー**：毎月 歩合前借り5万、発生歩合の50%までを翌月以降で相殺、未回収分は会社負担（生活は守る）。ただし「売上が読めない」本件では回収不安が生活を不安定化するため、年1は保証給方式が第一選択。売上が読めてきた2年目に歩合比率を引上げる。

## B. SNS・認知拡大戦略

### 前提の割り切り

BtoB・地方・経営者ターゲット・担当1名という制約下では、**SNSは「単独で客を連れてくる装置」ではなく、オフライン（河北新報・商工会議所・サウナ/経営者コミュニティ）で作った接点を"信頼できる専門家"として裏付け・維持する装置」** と割り切る。

- **主戦場**＝LINE公式（体験会予約・見込み客の保有と再接触）とFacebook（50人未満の地元経営者・50代前後に最も届く）
- **信頼資産**＝Instagram/note（睡眠×サウナの実体験を可視化）
- **拡散素材**＝YouTubeショート/リール（サウナ体験会の空気感）
- **KPIはフォロワー数にしない**。追うのは「体験会申込→商談化→顧問成約」
- 初年度成約5〜20社の規模なら **狭く濃く**（黒川郡・大和町＋仙台圏の中小経営者）

### B-3. 1名で回す週次運用

**鍵＝新規に毎回ゼロから作らない。**

- **(A) 源泉は実務そのもの**：体験会1回で写真20枚・動画・受講者の声・当日スライドが手に入る。分解すればFB/IG/ショート/note/LINEで**10〜15本**になる。
- **(B) 週次の現実ライン**

| 媒体 | 頻度 | 制作の性質 |
|------|------|-----------|
| Facebook | 週2〜3本 | 1本5分の事例・ニュース解説中心 |
| Instagram | フィード週2＋リール週1 | 体験会シーン切り出し |
| YouTubeショート | 月2本 | 体験会撮影のついで、編集最小 |
| note | 月1〜2本 | 使い回しの元原稿 |
| LINE公式 | 隔週1配信 | 小ネタ＋次回体験会案内 |

→ **新規制作は実質週2〜3コンテンツ**、残りは使い回しと切り出し。月20〜25本が目安。

- **(C) 省力化**：Canvaでテンプレ5種（事例/統計/セミナー告知/認定解説/人柄）を作り差し替えるだけ。撮影はスマホ、動画はテンプレ字幕のみ、月初1時間で投稿カレンダーをバッチで埋める。
- **(D) AI下書き活用**：実務メモを渡して投稿文の下書きを作らせ、小林は事実確認と表現チェック（景表法観点）だけ。
- **(E) 完璧を捨てる**：プロ品質より「地元の専門家が続けている」継続の可視化を優先。繁忙期は使い回し比率を上げ途切れさせない。

### B-4. SNS→体験会→顧問の導線

**導線は3段（認知→関係構築→成約）。各SNSのゴールは"LINE公式友だち追加"の一点に統一。**

1. 全SNSのプロフィール・投稿末尾・固定投稿に「体験会予約はLINEから」を配置。リンクはLINE公式（またはLINEに繋がる体験会LP）1本に絞る。
2. **体験会LP**（ペライチ/STUDIO等で1枚、コスト最小）に置くもの：誰向けか（50人未満の地元中小の経営者/人事）／当日の流れ（睡眠測定＋サウナ体験＋健康経営ミニ講義）／参加費（無料〜8万の該当メニュー）／小林プロフィール（元アクサ・中立）／参加者の声／日程／LINE予約ボタン。
3. **LINE登録直後**にあいさつメッセージで「睡眠セルフチェック」「プレゼンティーイズム簡易試算」などの小プレゼントを渡し、以後隔週配信で関係維持。
4. **体験会当日＝商談の起点**。測定結果の自社分布を見せ「継続的に測って施策に落とすなら顧問」へ自然接続。その場で初月分析（10万）の提案or後日個別面談へ。
5. **体験会に来ない層（FB/note読者）** にはLINE内で「オンライン15分無料相談枠」を用意し、体験会を飛ばして商談に入る裏ルートも確保。
6. **SNSは予約を取るまでが役割。クロージングは対面・LINE個別で行う。**

| **河北新報「健康みやぎサポーターズ」登録・連携** | 県内メディア×健康テーマの数少ない露出枠。取材/寄稿で「新聞に載った地元の専門家」の権威をSNS・LPに転用（スクショ＋リンク）。地方は紙・地元紙の信頼が経営者に効く |

### B-7. やるべき・避けるべき（景表法注意）

**DO（やるべき）**

- 体験の主観と公的統計・自社実績（出典明記）だけで語る。例「サウナ後はよく眠れたと感じる方が多い」「厚労省/健康経営度調査によると」は可
- プレゼンティーイズム等の数値は必ず**出典・年・調査主体**を添える
- 代理店・事業者としての立場を開示し「保険とは分離したコンサルである」旨を誠実に示す（ステマ規制・景表法2024改正で事業者の関与明示は必須）
- **投稿前チェックリスト**（効能断定なし/数字に出典/最上級なし/事業者立場明示/個人の感想明記）を1枚作り、小林が全投稿を通す運用にする

**DON'T（避けるべき）**

- 「治る・改善する・予防できる・効く・デトックス・免疫力が上がる」等の医薬品的/断定的効能表現（薬機法/健康増進法違反リスク）
- 「必ず生産性が上がる・離職率が下がる・認定が取れる」等の効果保証・断定（優良誤認＝景表法）。「目指せます」「事例では…でした」に留める
- 「宮城No.1・唯一・日本一」等の最上級/No.1表現を客観的根拠（調査出典）なしに使う（優良誤認）
- 体験者の声・ビフォーアフターを効能の証明として使う（「個人の感想」と明記、医療類似表現に踏み込まない）
- サウナの健康効果を医療的に断定する（温冷交代浴の医学的効能を謳うと医療・薬機法領域）。「リフレッシュ」「対話が生まれる場」など体験価値で表現

## C. 売り方（集客〜受注の営業設計 / GTM）

### 勝ち筋の核心

実績ゼロ・無名・担当1名・無料競合ありという条件では、**「価格と規模で戦わず、実体験と数値で戦う」** のが唯一の勝ち筋。

1. **無料勢（商工会議所・協会けんぽ・アクサ等）は敵でなく"入口の送客チャネル"** として使い、その先の実行支援（伴走）を有料で握る。無料支援は診断・宣言まで、社員の睡眠・疲労が実際に変わる打ち手は誰も持っていない＝ここが光和の独占領域。
2. **睡眠測定×サウナの実体験を"経営者本人がまず体感する"入口** にし、「言葉で説明する健康経営」を「体で分かる健康経営」に変える。無名でも体験は裏切らない。
3. **担当1名の伴走上限6〜10社という物理制約** から、初年度は「広く薄く見込みを集め、狭く深く顧問を取る」設計。モニター価格＋共同事例づくりで最速5社の事例を作る。**現実解＝成約5〜12社（基本350〜600万）。**

### C-3. 営業プロセス

**① 初回接触で聞くこと（まず売らない）**
- 従業員数・平均年齢・交代勤務や現場作業の有無（建設/リフォーム/ランドリーは睡眠負債と親和性が高い）
- 直近の離職・欠勤・労災・メンタル不調の有無と体感的コスト
- 健康経営や職場健康づくり宣言の認知度・過去の取組と挫折理由
- 経営者自身の睡眠・疲労の自覚
- 採用難の度合い

→ 「健康経営に困っていますか」でなく **「最近、辞める人・体調崩す人いませんか」「社長ご自身、よく眠れてますか」** から入る。

**② 体験で見せること**
経営者本人にサウナ＋睡眠測定を体験させ、翌日以降のデータ変化を見せる。「説明」でなく「体感」。加えて他社の匿名事例（睡眠負債の損失額、認定取得で採用が変わった話）を1〜2本。**無料勢が絶対に見せられない「実際に体が変わる」瞬間** を作る。

**③ 提案で数値化すること（全て"御社の数字"で1枚に）**
- 自社の測定/アンケート結果→プレゼンティーズム損失額に換算（例：1人あたり年◯万円の生産性損失×人数）
- 顧問料 年55〜65万に対する投資対効果（損失削減・離職1人あたり採用コスト◯十万の回避・認定取得による採用力/入札加点）
- 認定取得までの工程表と役割分担

**④ クロージング**
即決を狙わず「**6ヶ月区切り＋モニター価格＋事例掲載**」で心理的ハードルを下げる。認定申請の締切から逆算し「今月開始しないと今年度の認定に間に合わない」という自然な期限を提示。決裁は経営者本人がいる体験会・提案で完結させ、稟議を挟ませない。最後に「まずは全社測定だけでも」と第1段への降り口も用意し取りこぼさない。

### C-5. 紹介の仕組み

**依頼タイミングは「満足度がピークになる瞬間」に固定**：① 認定取得が決まった時、② 睡眠スコアや欠勤が目に見えて改善した四半期レビュー時、③ 社長自身の睡眠が良くなったと実感した時。

**言い方は売り込まず「成果の共有」の形に**：
> 「◯◯社長のところ、認定も取れて社内も変わってきましたよね。同じように困っている経営者仲間、心当たりありませんか。まずウチの体験会に無料でご招待しますので、社長からお声がけいただけると」

**特典は双方向**：
- 紹介元＝次回顧問料1ヶ月分割引 or 上位サービス無料オプション
- 紹介先＝体験会・全社測定の無料枠

組合・業界団体・経営者の会など「横のつながり」単位でまとめて体験会を打つと、1回の依頼で複数リードが取れる。**事例掲載許諾は契約時にセットで取り**、紹介トークの実弾（他社の成果）を常に補充し続ける。

### C-6. 提携戦略

| 提携先 | 位置づけ・役割分担 |
|--------|------------------|
| **社労士・税理士（送客提携の本命）** | 助成金・就業規則で中小と接点を持つが「睡眠・健康の実行支援」は守備範囲外。認定申請実務を面倒がる士業が多いので「実行部分は光和が巻き取る」と役割分担を明確化し、顧問契約が決まったら紹介手数料or相互送客。士業の顧問先＝温かいリストの宝庫 |
| **商工会議所/協会けんぽ（入口の共催）** | 敵視せず「無料の入口を作ってくれる装置」と位置づける。先方は診断・宣言・啓発まで、その後の伴走リソースがない。共催で登壇枠をもらい、意識が高まった企業の「次の一歩（有料の実行支援）」を受け皿に。先方のKPI（宣言数・認定数）達成にも貢献しWin-Win |
| **保険代理店・アクサ等の全国勢** | 価格では勝てないが、彼らは「保険で回収」が目的で睡眠・サウナの実体験の手札がない。地域案件で「実行支援は光和、保険は御社」の補完提携もあり得る。真正面から価格勝負しない棲み分けを設計 |
| **地銀・信金** | 取引先の健康経営・事業承継・採用課題に関心。顧客向けセミナー登壇や送客提携で、信用の裏付け（無名の弱点補完）と質の高いリードを同時に得る |
| **サウナ・ランドリー等の自社アセット** | これ自体が他社にない「提携不要の武器」。体験会の会場・物販・実行支援の現場として最大活用し、差別化の核に据える |

### C-7. 断り文句への切り返し

| 断り文句 | 切り返し |
|----------|---------|
| **予算がない** | 「だからこそ、まず御社の"今の損失額"を測らせてください」。睡眠負債による生産性低下や1人離職の採用コスト（数十万）を数値化し、顧問料は損失の一部を回収する投資だと示す。使える助成金・初年度モニター価格・6ヶ月区切りを提示し、まず無料の全社測定だけでも受けてもらう |
| **無料でやってもらえる（商工会議所・協会けんぽ）** | 「無料の診断や宣言はぜひ活用してください。むしろ一緒に使いましょう」と肯定した上で、「でも"宣言した後、実際に社員の睡眠や疲労が変わりましたか"」と問う。無料勢は診断・宣言まで、実行の伴走と睡眠×サウナの実体験は誰も提供していない＝ここが有料の価値だと線引き。無料は敵でなく前工程 |
| **効果が分からない/本当に変わるのか** | 「言葉ではなく、まず社長ご自身で体感してください」と体験会へ。測定でビフォー/アフターの数値を出し、認定取得という到達点を明確なゴールに。契約は6ヶ月区切り＋四半期の数値レビューにし、成果が見えなければ続けなくてよい形でリスクを先方から取り除く |
| **忙しくて時間がない** | 「社長のお手間は最小にします。実行は私が巻き取ります」。経営者が動くのは体験会と四半期レビューの年数回だけ、測定や申請実務は光和が代行。むしろ「忙しくて社員の不調に手が回らない状態こそ離職と生産性低下のリスク」と放置コストに転換して危機感に変える |
| **大手やアクサの方が安心** | 「全国対応の大手にはできないことをやります」。大手は保険回収が目的で担当も転勤し、睡眠×サウナの実体験も地元密着の伴走もない。光和は元アクサの中立性（保険は従・完全分離）と地元で顔が見える継続支援、実際に体が変わる現場を持つ。価格・規模で競わず密着と実体験で差別化 |

### C-8. 最初の90日の動き

最初の90日は **「売上より事例と型づくり」**。この間の報酬は固定を抑え、体験会本数・第1段診断販売数・顧問受注数のKPI連動にして「読めない売上」のリスクを人件費に転嫁しない（→A章と連動）。
