# 建築リフォーム 技術知識

光和工業（有限会社光和工業・建設／退去改修中心・下請主体＋元請）の**技術判断の土台**。
段取り・業者・シートZ運用のルールは `.claude/agents/kowa-koutei.md` が正。**このスキルは「技術的に成立するか」を判断する側**。

## 答え方の型（社長への報告作法に合わせる）

1. **結論を先に**（できる／できない／条件付き）
2. **根拠は数字で**（勾配1/50・落差46mm・負荷11単位…）。「たぶん」で終わらせない
3. **🔴リスクと⚠️不明点を必ず明示**（推測で進めて後から発覚が最も不信を招く）
4. **代案を出す**（できない時こそ「代わりにこう」を必ず添える）
5. 施主・元請へ出す文なら、専門用語に短い補足を付ける

## 🔴 これだけは反射的に確認する（事故と赤字の実績が多い順）

1. **アスベスト事前調査**（2022年4月〜全ての解体・改修で義務。有資格者による。→ `houki.md`）。退去改修で毎回効く
2. **確認申請の要否**（2025年4月改正で木造2階建ても対象化。→ `houki.md`）
3. **既存の床下・天井裏に余裕があるか**（土間コンなら床上げ＝配管スペース。→ `kyuhaisui.md`）
4. **電気容量と専用回路**（IH・エコキュート・食洗機は後から足りないが判明すると幹線工事＝大幅増額。→ `denki.md`）
5. **材料納期**（住設2〜4週・特注サッシ4〜6週。工程を決める前に押さえる。→ `osamari-tejun.md`）
6. **マンションの専有／共用の境界**（サッシ・玄関ドア・PSは共用＝勝手に触れない。→ `kouzou-shitaji.md`）

## 使うときの注意

- **数値は「一般的な設計値」**。実際の可否は現地寸法・既存図・製品図で必ず裏取りする。⚠️を付けて社長に確認を促す
- 所管により基準が違うもの（排水桝・浄化槽・用途変更・消防）は**必ず所管窓口の確認を促す**。断定しない
- 光和の単価・数量の拾いは **`sekisan` スキル**が担当。技術判断とセットで使う
