## 👥 組織（部長＋7チーム）

あなた → **サウナ事業部長**（メインセッション）→ 各チーム（サブエージェント）。
部長が100点になるまで差し戻し、完成品だけを提出します。詳細は `組織体制.md`。

| チーム | エージェント名 |
|---|---|
| 予約管理 | `sauna-reservation` |
| SNS運用 | `sauna-sns` |
| 経理 | `sauna-accounting` |
| 顧客対応(CS) | `sauna-cs` |
| 運用保守(bot) | `sauna-ops` |
| 集客・PR | `sauna-pr` |
| 分析 | `sauna-analytics` |

## 🛠 スキル（繰り返し作業の「合言葉」）

リポジトリ直下 `.claude/skills/` に配置。セッションで一言いえば発動：

| スキル | いつ使う |
|---|---|
| `reservation-crosslock` | 予約が入った → カレンダー反映＋他チャネル売止 |
| `cancel-propagation` | キャンセルが入った → カレンダー更新＋売止解除 |
| `daily-summary` | 朝、今日のサウナ運営状態をまとめる |
