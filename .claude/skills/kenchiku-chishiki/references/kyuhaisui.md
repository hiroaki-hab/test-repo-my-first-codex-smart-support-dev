# 給排水・給湯

## 1. 排水勾配（最重要・ここで可否が決まる）

| 管径 | 最小勾配 | 1mあたり落差 | 管の外径 |
|---|---|--:|--:|
| VP40 | 1/50 | 20mm | φ48 |
| **VP50** | **1/50** | **20mm** | **φ60** |
| VP65 | 1/50 | 20mm | φ76 |
| **VP75** | **1/100** | **10mm** | **φ89** |
| **VP100** | **1/100** | **10mm** | **φ114** |
| VP125 | 1/150 | 6.7mm | φ140 |
| VP150 | 1/200 | 5mm | φ165 |

**必要な床上げ＝管外径＋(距離×勾配)＋床材厚＋支持金物の逃げ（20〜30mm）**

例）VP75で9m引く → 89＋90＋12＋20＝**約210mm**。FL+100では物理的に不可能。
例）VP50で2.3m → 60＋46＋12＋20＝**約140mm** → FL+150に収まる。

- 🔴 **勾配は取りすぎても悪い**。1/25より急にすると水だけ先に流れて固形物が残る（「洗い流し不足」）。1/50〜1/100が最良
- 逆に緩いと流速不足で堆積。**自然流下の適正流速は0.6〜1.5m/s**
- 土間コン（床下なし）の既存建物では、**床上げ寸法がそのまま配管スペース**。ここを最初に押さえる

## 2. 器具排水負荷単位（fixture unit）と管径選定

| 器具 | 単位 |
|---|--:|
| 大便器（タンク式） | 4 |
| 大便器（フラッシュバルブ） | 8 |
| 洗面器 | 1 |
| 手洗い | 0.5 |
| 浴槽・ユニットバス | 2〜3 |
| シャワー | 2 |
| キッチン流し（住宅） | 2 |
| 業務用シンク（二層） | 3〜4 |
| 洗濯機（防水パン） | 2〜3 |
| 食洗機 | 2 |

**横枝管の許容（勾配1/100時の目安）**：VP50=3単位／VP65=6／**VP75=12〜14**／VP100=24〜30／VP125=50

- 住宅規模なら **キッチン単独＝VP50、浴室系＝VP75、全部まとめ＝VP75〜100** が実務の相場
- ⚠️ 単位は「同時使用の確率」を織り込んだ値。**民泊・宿泊施設で同時使用が少なければ余裕がある**が、逆にホテル・寮の朝など一斉使用がある用途では余裕を見る

## 3. トラップ（臭い・ゴボゴボの原因はほぼここ）

- **封水深は50〜100mm**。これが切れると臭気が室内に上がる
- 🔴 **二重トラップは禁止**。器具トラップ＋もう1つのトラップが直列になると、間の空気が逃げず**流れなくなる／ゴボゴボ鳴る**
  - 器具（UB・洗面・キッチン）は**それぞれトラップ内蔵**。器具同士を合流させるだけなら二重にならない
  - 🔴 **危ないのは合流先が「トラップ桝（防臭桝）」の場合**。既設桝の種類は必ず確認する
- **封水が切れる4パターン**
  1. **自己サイホン**（自分の排水の勢いで自分の封水を引く。洗面に多い）
  2. **誘導サイホン**（上階・他器具の大量排水で立管が負圧→吸い出す。UBの浴槽200L一気落としが典型）
  3. **蒸発**（長期不使用。空き家・民泊の閑散期。→ 封水蒸発防止剤／定期通水）
  4. **毛細管現象**（毛髪がトラップに引っかかって水を吸い出す）
- **トラップから通気までの距離**（トラップウェア長）は**1.5m以内**が目安。長いと自己サイホンを起こす

## 4. 通気

| 方式 | 内容 | 使いどころ |
|---|---|---|
| 伸頂通気 | 排水立管をそのまま屋上へ立ち上げる | 戸建の基本 |
| ループ通気 | 2器具以上の横枝管から通気管を取る | 器具が並ぶ場合 |
| 各個通気 | 器具ごとに通気 | 確実だが高価 |
| **通気弁（AAV/ドルゴ）** | 負圧時だけ空気を吸う弁 | **改修で通気管を出せない時の定番** |

- 🔴 **通気弁は負圧にしか効かない（正圧＝吹き返しには無力）**。立管の最下部・排水が集中する所には使えない
- 🔴 **通気弁は「点検・交換できる位置」に付ける**。壁の中に埋め殺しにしない（消耗品・寿命10年程度）
- 通気管を屋外へ出す場合、**窓・給気口から3m以上離す**（臭気の逆流防止）
- 系統末端（最上流）に通気を入れるのが効く

## 5. 掃除口・排水桝

- **掃除口**：VP100以下は**15m以内**ごと、VP125以上は30m以内。**曲がり部（45°超）には必ず**
- **排水桝を置く位置**：①起点 ②合流 ③曲がり ④勾配・管径の変化点 ⑤直線部は**管径の120倍以内**（VP100なら12m）
- 桝の種類：インバート桝（汚水）／トラップ桝（雑排水の臭気止め）／会所桝
- ⚠️ 公共桝の位置・深さで全体の勾配が決まる。**現調で公共桝の深さを必ず実測**する

## 6. 混ぜてはいけない組み合わせ（詰まりの実態）

- 🔴 **キッチン（油脂）＋浴室（毛髪）を1本にすると固着して詰まる**——最も多い詰まり方。最低でもキッチンは分ける
- グリストラップ（業務用厨房）は**用途変更・飲食営業許可で要求される**ことがある。保健所確認
- 洗濯機排水は糸くず。防水パンのトラップは点検可能に

## 7. 給水・給湯

- **給水は圧力で送るので勾配不要**。ただし凍結深度（仙台は概ね **GL-500mm以深**、山間部はもっと深い）と、水抜き栓の要否を確認
- **さや管ヘッダー工法**：ヘッダーから各器具へ1本ずつ。同時使用でも湯温が安定・後の更新が容易。改修でも推奨
- **給湯器の号数**：16号＝1〜2人／20号＝2〜3人／**24号＝4人家族の標準**。追い焚き（オート／フルオート）の有無で配管本数が変わる
- **エコキュート**：貯湯タンク重量（370Lで満水約400kg）＝**基礎が必要**。200V専用回路。ヒートポンプの低周波音で近隣クレーム例あり、隣家寝室側を避ける
- **給湯配管の保温**は必須（熱損失＋結露）。ヘッダーからの分岐は保温材で被覆
- 🔴 **架橋ポリ・ポリブテンは紫外線に弱い**。屋外露出部は必ず保温＋テープ巻き

## 8. 現調で必ず見る（抜けると後で崩れる）

- [ ] 既存は土間コンか床下ありか。**床下有効寸法**（土間なら床上げ可能量）
- [ ] 公共桝の位置・深さ／既存桝の種類（トラップ桝か）
- [ ] 既存排水管の材質・口径（鉄管なら腐食＝更新推奨）
- [ ] 上下階・隣戸への影響（マンションはPS位置と床スラブ厚）
- [ ] 給湯器の号数・設置形式（壁掛/据置）、既存配管の位置
- [ ] 電気容量（→ `denki.md`）と同時に見る
