## 塗装業者さんへの支払予算(税抜・外注単価)

| 項目 | 数量 | 外注単価 | 予算 |
|---|---|---|---|
| 高圧洗浄 | 221㎡ | 200 | 44,200 |
| 下地調整(ケレン・錆部補修) | 221㎡ | 800 | 176,800 |
| シリコン塗装(錆止め+上塗り2回) | 221㎡ | 2,500 | 552,500 |
| 養生 | 1式 | 30,000 | 30,000 |
| 外壁タッチアップ(4〜5か所) | 1式 | 25,000 | 25,000 |
| **合計** | | | **828,500** |

- 幅: 安め約65万円(洗浄150/下地600/塗装2,000/養生2万/タッチアップ2万)〜高め約95万円(200/1,000/2,800/4万/3万)
- 認定額1,404,950円に対し、予算828,500円なら当社粗利 約576,000円(約41%)
- 発注時は「足場は当社支給」「錆止め込みの3回塗り」「シリコン系」を条件に明記

## 決定(2026-10-07)

- **社長が塗装業者さんと 800,000円(税別、税込880,000円)で合意**
- 認定額1,404,950円との差 = 当社粗利 604,950円(約43%)
