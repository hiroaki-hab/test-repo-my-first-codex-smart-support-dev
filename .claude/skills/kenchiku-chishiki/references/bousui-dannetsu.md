# 防水・断熱・結露

## 1. 雨漏りの三大発生源（原因究明はこの順で疑う）

1. **開口部まわり**（サッシ上・両サイド）＝防水テープの張り順ミス、シーリング切れ
2. **屋根と壁の取合い**（雨押え・水切り・谷）＝板金の納まり
3. **笠木・パラペット・手摺根元**＝バルコニー笠木のジョイント、手摺のビス穴

- 🔴 **雨染みの位置と侵入口は一致しない**（水は下がりながら横に走る）。散水試験で特定する
- シーリングは**消耗品（10年前後）**。「打ち増し」でなく**打ち替え**が原則（既存を撤去してから）
- サッシまわり防水テープは**下→両サイド→上**の順（上を最後に重ねて水を逃がす）。逆は漏る

## 2. 防水の種類と改修

| 工法 | 用途 | 耐用 | 改修 |
|---|---|--:|---|
| **FRP防水** | 木造バルコニー | 10〜15年 | トップコート5年毎／全面は下地から |
| **ウレタン塗膜** | 陸屋根・バルコニー | 10〜13年 | 通気緩衝工法で既存の上から可 |
| **塩ビシート** | 陸屋根 | 13〜20年 | 機械固定で既存の上から可 |
| **アスファルト** | 大規模陸屋根 | 15〜25年 | — |

- 🔴 **既存に水が入っている（含水）状態で塗膜防水を被せると膨れる** → **通気緩衝シート＋脱気筒**
- **浴室**：ユニットバス（UB）は防水パン一体＝**下地防水は不要**。**在来浴室は防水層が必須**（UB→在来は別世界）
  - 在来からUBへの改修は**土間・基礎の斫り**が入る。段差・排水位置の調整が必要（→ `kyuhaisui.md`）

## 3. 断熱：費用対効果の順

1. **内窓（インプラス等）** … 最も効く／工期半日／補助金が厚い（先進的窓リノベ）
2. **天井（小屋裏）断熱** … 施工容易・効果大
3. **床下断熱** … 床下に入れれば容易
4. 壁（充填断熱） … 内装解体が要る＝リフォームついでが前提

- **開口部からの熱損失は冬で約58%、夏で約73%**。窓を先に手当てするのが定石
- 内窓のガラス仕様：単板／複層／Low-E複層。**補助金の等級は仕様で変わる**ため、見積前に等級を確定させる（→ 苦竹BASEの教訓）
- 光和の窓・建具・外構は **千葉住建**、補助金書類は `kowa-subsidy-mado` エージェント

## 4. 結露

- **表面結露**＝断熱不足・換気不足。窓・北側の壁・押入れ・家具裏
- 🔴 **壁内結露（内部結露）が構造を腐らせる**。防湿層（室内側の防湿フィルム）を破らない。断熱材を入れるときは**室内側＝防湿／屋外側＝透湿防水**の順を守る
- **気密を上げたら換気とセット**。内窓・断熱を入れて換気が悪いと、結露・カビが必ず出る（→ `denki.md` 24時間換気）
- カビ処理：塩素系で殺菌 → 乾燥 → **防カビシーラー** → 仕上げ。表面を貼り替えるだけでは再発

## 5. 外壁塗装まわり（技術面）

- 🔴 **気温5℃以下／湿度85%以上は塗装不可**（仙台の12〜3月は要注意。朝夕の結露も）
- 工程：高圧洗浄 → 乾燥（1日以上）→ 下地補修（クラック・シーリング）→ 下塗 → 中塗 → 上塗 → 付帯
- **各工程のインターバル（乾燥時間）を守る**。詰めると剥離する。光和の標準は**塗装期間3週間**（`kowa-koutei.md`）
- 窯業系サイディングは**シーリング打ち替えとセット**。塗装だけしてシールを残すと数年で切れる
