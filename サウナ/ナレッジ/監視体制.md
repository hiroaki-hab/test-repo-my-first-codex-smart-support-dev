## 1. 稼働中の自動化（Python bot v3.6）

佐藤様PC `C:\KowaBot\` で動作中。Windowsタスクスケジューラに3つ登録：

| タスク | 間隔 | 役割 | 状態 |
|---|---|---|---|
| **KowaBot-Keepalive** | 5分毎（営業時間中） | SB＋CHILLNN のセッション維持 | ✅稼働中 |
| **KowaBot-Reconcile** | 1時間毎 | カレンダー基準でCHILLNN＋SBを全件突合・修正 | ✅稼働中 |
| **KowaBot-CancelWatch** | 10分毎 | Gmailのキャンセル通知監視（実装は最小限） | ✅稼働中 |

### PCを起動したまま放置したときの自動挙動
1. 5分毎：bot が SB に navigate して Cookie をアクティブ維持
2. 1時間毎：Googleカレンダーを読み、CHILLNN/SB の差分を修正
3. 10分毎：Gmailのキャンセル通知をチェック（処理は手動 or 後日実装）

## 3. 毎日の確認方法

### Python bot のログ
```cmd
type C:\KowaBot\logs\YYYY-MM-DD.log
```
読みどころ：
- `SB session alive: True/False` … SBセッションの生死
- `CHILLNN session alive: True/False` … CHILLNNセッションの生死
- `=== End: keepalive OK ===` … keepalive正常
- `=== End: reconcile OK ===` … 同期完了

### 🔔 緊急対応の合図
- `SB session alive: False` が**連続**したら緊急対応（手動再ログインが必要な可能性）
- ⚠️ 現状、SB切れの**即時通知は未実装**（botは黙ってログに残すだけ）。v3.7の最優先課題
