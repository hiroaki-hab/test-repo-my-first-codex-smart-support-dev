# 単価体系（3系統の使い分け）

## 🔴 系統A：一般リフォーム（直請・元請案件）

**売単価 ＝ 業者原価 ÷ 0.85（100円未満切捨て）**

- 出典：光和の基本ルール
- 粗利率は 15%（÷0.85）だが、ここに**諸経費10%**が乗るため、工事全体では**25〜30%**に着地する
- 参照：`C:\kowa-automation\mitsumori_gakushu\単価マスター.md`（過去見積938件・明細11,794行・30工事種）
  - 諸経費／解体撤去／内装（クロス・床・その他）／トイレ／洗面／キッチン／浴室／給湯／給排水／電気／設備機器／建具／サッシ／塗装（外壁・屋根・内部）／外壁／屋根／樋／防水／基礎／左官／タイル／木工事／エコカラット／ガラス／外構／その他
  - ⚠️ 単価には**(売)と(原)が混在**。各行の表記を確認する。原のみの行は ÷0.85 で売価化

## 単価が無いときの決め方

1. **単価マスターで近い工種を探す**（最頻〜中央値ベース。極端な最大値＝一式総額は単価ではない）
2. 過去の同種物件の見積を探す（`\192.168.100.250\共有ファイル\` の年度フォルダ）
3. **業者に相見積を取る**
4. ⚠️ それでも不明なら**空欄＋⚠️で残す**。仮値を黙って入れない
