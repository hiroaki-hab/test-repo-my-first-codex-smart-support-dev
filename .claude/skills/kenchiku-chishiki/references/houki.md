# 法規・届出

> ⚠️ **最終判断は所管（特定行政庁・消防・保健所・水道局）へ確認する**。ここは「引っかかる可能性を見落とさない」ためのチェック用。断定して社長に伝えない。

## 1. 🔴 アスベスト事前調査（光和の全案件に効く・最重要）

- **2022年4月〜、全ての建築物の解体・改修工事で「事前調査」が義務**（規模・金額を問わず。壁紙1枚剥がす工事でも調査対象）
- **2023年10月〜、調査は「建築物石綿含有建材調査者」等の有資格者**でなければならない
- **報告義務**（労基署・自治体へ電子報告）＝**解体部分の床面積80㎡以上／改修工事の請負金額100万円以上（税込）／特定の工作物**
- 調査方法：**設計図書＋目視**。判断できない建材は**分析**か「含有みなし」で対応
- 🔴 **2006年9月以前の建物はほぼ全て要注意**。特に：
  - **レベル1**（吹付け）＝天井・機械室。除去は隔離・負圧
  - **レベル2**（保温材・耐火被覆・煙突断熱）＝配管の保温材
  - **レベル3**（成形板）＝**スレート・けい酸カルシウム板・Pタイル・ビニル床タイル・石膏ボード・外壁サイディング・煙突材**。**退去改修で最も遭遇する**
- **記録は3年保存**、現場に**調査結果の掲示**が必要
- 見積に**調査費用を計上する**（未計上＝赤字要因）

## 2. 建築確認申請が必要になるリフォーム

| ケース | 申請 |
|---|---|
| 10㎡超の増築（防火・準防火地域は面積問わず） | **必要** |
| **大規模の修繕・模様替**（主要構造部＝壁・柱・床・梁・屋根・階段の**一種以上の過半**） | **必要**（下記★） |
| 用途変更（特殊建築物へ・**200㎡超**） | **必要** |
| 内装・住設交換・クロス・床の張替 | 不要 |
| 耐震改修（既存の範囲内） | 原則不要（要相談） |

★ **2025年4月改正のポイント（光和に直撃）**
- 従来「4号特例」で審査省略だった**木造2階建て・木造平屋（200㎡超）が「新2号建築物」となり、大規模の修繕・模様替でも確認申請が必要**になった
- 特例が残るのは**木造平屋かつ200㎡以下（新3号）**のみ
- 🔴 実務影響：**屋根の全面葺き替え・外壁の過半の張り替え・床の過半の張り替え**などが「過半」に当たると申請が要る。**申請図書・構造関係の資料作成＝費用と期間（1〜2ヶ月）が発生**する
- 🔴 **既存不適格・検査済証なしの物件は申請が通らないことがある**。着手前に建築士・所管へ相談を促す

## 3. 用途変更（民泊・簡易宿所・店舗）

- **200㎡超**の特殊建築物への用途変更で確認申請。**200㎡以下なら建築確認は不要**（ただし下の適合義務は残る）
- 🔴 **「確認申請が不要＝何もしなくてよい」ではない**。**建築基準法の実体規定（内装制限・避難・排煙・採光・防火区画）には適合させる義務がある**
- 民泊・簡易宿所には別途：
  - **旅館業法（簡易宿所営業）または住宅宿泊事業法（民泊新法・年180日上限）** … 保健所
  - **消防法令適合通知書** … 消防署（**自動火災報知設備・誘導灯・消火器**が要求されることが多い）
  - 用途地域の確認（住居専用地域では旅館業不可の場合あり）
- 実例：**富谷ヴィレッジ**は「簡易宿所への変更面積150.93㎡（全体237.02㎡）」＝**200㎡以下に収めて確認申請を回避する設計**。この意図を壊す変更（面積追加）を提案しない

## 4. 消防

- **住宅用火災警報器**：寝室＋階段上部（→ `denki.md`）
- **防炎物品**：高層・特定防火対象物のカーテン・じゅうたん
- 用途変更時は**消防への事前相談が必須**。設備の要否で工事費が数十万〜変わる

## 5. 建設リサイクル法

- **届出が必要**：解体80㎡以上／新築・増築500㎡以上／修繕・模様替1億円以上／土木2,500万円以上
- **着工7日前まで**に都道府県知事へ届出。分別解体・再資源化が義務
- **産廃はマニフェスト**（電子マニフェスト推奨）。運搬・処分の許可業者を使う

## 6. 建設業法

- **軽微な工事＝許可不要**：建築一式工事は**1,500万円未満または延面積150㎡未満の木造住宅**／それ以外の専門工事は**500万円未満**（いずれも税込）
- 🔴 **500万円以上の専門工事（内装・管・電気等）を許可なく請ける／下請に出すのは違反**。業者の許可の有無を確認する
- **一次下請への発注総額4,500万円以上**（建築一式7,000万円以上）＝特定建設業許可＋施工体制台帳
- **契約は書面**（注文書・請書でも可。電子契約可）。**追加変更も書面**にする（口頭の追加工事は回収不能リスク）

## 7. 設備の資格・指定

- **給水装置工事**：水道局の**指定給水装置工事事業者**＋主任技術者でなければ施工不可
- **排水設備工事**：下水道の**指定工事店**＋責任技術者
- **電気工事**：電気工事士（→ `denki.md`）
- **浄化槽**：設置届／保守点検・清掃・法定検査の義務

## 8. その他

- **省エネ基準適合義務**（2025年4月〜）：原則すべての新築。**増改築は増改築部分が対象**。リフォーム単体は対象外だが、増築を伴う場合は要確認
- **住宅瑕疵担保履行法**：新築が対象。リフォームは**リフォーム瑕疵保険**（任意・任意加入で受注の武器になる）
- **介護保険住宅改修**（上限20万円・9割給付）：手摺・段差解消・扉交換・便器交換。**着工前の申請が必須**（事後申請不可）
- 補助金：先進的窓リノベ等 → `kowa-subsidy-mado` / `kowa-subsidy-watch` エージェント

## 9. 見積・現調で反射的に確認

- [ ] 築年（2006年9月以前 → アスベスト調査を見積計上）
- [ ] 工事範囲が「過半」に当たるか（→ 確認申請の要否を建築士へ）
- [ ] 用途変更の有無・面積（200㎡の線）
- [ ] 解体面積80㎡以上か（建設リサイクル法の届出）
- [ ] 請負金額が500万／1,500万の線を越えるか
- [ ] 給排水は指定工事店で施工するか
