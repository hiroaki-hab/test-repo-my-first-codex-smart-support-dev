# 構想：補助金 網羅監視・提案体制（全BtoB共通の武器）2026-06-04

> 社長指示：BtoBは補助金という選択肢を忘れない。お客様の事業に合う・使えそうな補助金を**網羅的に監視し、常に提案できる状態**を作りたい。サウナ事業にも言える。
> ＝ サウナ／チラー水風呂／ブレインスリープ／コインランドリー／リフォーム、**全部の設備投資提案で"補助金"がクロージングの決め手**になる。

## 部長の評価
「設備を売る」会社は多いが「**使える補助金まで添えて提案できる**」会社は少ない。これは**全事業の成約率を底上げする横断ケイパビリティ**。AIチームの得意領域(網羅監視・マッチング)とも相性が良い。

## 監視対象になりうる補助金（例・⚠️制度/予算は年度で変動＝要・最新公募確認）
| 補助金 | 主な用途 | 当社事業との接点 |
|---|---|---|
| ものづくり補助金 | 設備投資・革新的サービス | サウナ/水風呂/ランドリー機器の設備投資 |
| 小規模事業者持続化補助金 | 販路開拓・小規模の設備/広報 | 小規模店・開業者の設備＋チラシ |
| 省エネ補助金(省エネ設備導入) | 高効率機器への更新 | 高効率乾燥機・チラー・空調・ヒーター |
| IT導入補助金 | 予約/管理/会計システム | サウナ予約・店舗管理・会計効率化 |
| 業務改善助成金 | 設備＋賃上げ | 事業者の設備投資＋人件費 |
| 事業再構築補助金 | 新分野転換(※縮小傾向) | リフォーム業→サウナ等の新事業 |
| 介護・福祉系補助 | 介護環境整備 | 介護施設へのブレインスリープ等 |
| 自治体の創業/設備/省エネ/熱中症対策補助 | 地域別 | 出店・熱中症対策アイスバス 等(地域で要確認) |

## 監視のしくみ（AIチーム活用）
1. **公的ソースを定期巡回**：中小企業庁／ミラサポplus／J-Net21／jGrants／宮城県・各自治体の補助金ページ。
2. **一覧台帳を維持**：補助金名・対象・補助率/上限・公募期間・要件・出典URL を表で更新(月次＋公募期は随時)。
3. **顧客事業 × 補助金 のマッチング表**：業種/投資内容から「使える候補」を即引ける状態に。
4. **案件時に即提案**：見積に「活用できる補助金候補」を添える(成約率UP)。

## 運用ルール（正直に・守る）
- 当社/AIの役割は**「網羅的な情報提供と提案」まで**。**申請代行・要件可否の最終判断・採択保証は専門家(行政書士・認定支援機関)領域**＝橋渡しする。
- **誇大NG**(「必ず通る」等は言わない)。制度は流動的＝**必ず最新の公募要領を確認**してから提案。
- 補助金ありきで不要投資を勧めない(顧客本位)。

## 適用（全事業に効く）
- サウナ/チラー水風呂：省エネ・設備・熱中症対策(自治体)
- ブレインスリープ：介護施設の福祉系補助
- コインランドリー：開業・省エネ高効率乾燥機
- リフォーム本業：各種設備・省エネ

## まず動くなら
1. **補助金台帳(スプレッドシート)を1枚作成**し、上表の主要補助金を初期登録。
2. AIチームに**「補助金ウォッチ」機能**を持たせ、月次更新＋公募期アラート。
3. 各事業の提案資料に**「使える補助金候補」欄**を標準装備。
4. 連携先(行政書士/認定支援機関)を1つ確保し、申請は橋渡し。
