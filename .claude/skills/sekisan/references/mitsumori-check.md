# 見積のチェックリストと様式

## 1. 拾い漏れチェック（この順で当てる）

### 全案件 共通
- [ ] **養生費**（作業室・作業経路。マンションは共用部・EV も）
- [ ] **産業廃棄物 運搬処分費**（㎥。混載18,000円/㎥）
- [ ] **資材機材 運搬費**（場内小運搬）
- [ ] **家財（家具）移動・復旧費**（居ながら工事は必須）
- [ ] **クリーニング／美装**（光和ではなく**MCB**へ発注）
- [ ] **諸経費 ＝ 工事費小計 × 10%**
- [ ] **値引き**（端数調整・最後に千円丸め）

### 外装・塗装がある場合
- [ ] 外部足場（掛面積＝(外周+8m)×軒高）
- [ ] 高圧洗浄
- [ ] 安全対策費／昇降設備
- [ ] シーリング打ち替え（塗装だけしてシールを残さない）

### マンションの場合
- [ ] EV（エレベーター）養生・共用部養生
- [ ] 有料駐車場使用料
- [ ] 2F以上の資材搬入・搬出費
- [ ] 管理組合への申請（工事時間・休日作業の制約）

### 築古・解体がある場合
- [ ] 🔴 **アスベスト事前調査費**（2006年9月以前は必ず。有資格者による調査が義務）
- [ ] 分別解体・建設リサイクル法の届出（解体80㎡以上）
- [ ] 仮設トイレ・仮設電気水道

### 住設入替がある場合（廣田邸の教訓）
- [ ] 🔴 **発注内訳書の全項目を業者へ割り付けたか**（1項目でも漏れると粗利が跳ね上がって見え、実際は赤字になる）
- [ ] 解体撤去／給排水切り回し／電気配線／大工造作（額縁・下地）／内装復旧／搬入費
- [ ] 洗濯機まわり・洗面まわりなど「ついで工事」の計上漏れ

## 2. 粗利の検証

- **枠は25〜30%**（社長の経営目標。粗利25→30%が再建方針）
- **30%を超えたら疑う** … 項目・数量の漏れ、業者予算の割り付け漏れ
- **25%を切ったら見直す** … 単価の誤り、値引きしすぎ、想定外の付帯工事
- 退去（系統B）の内装は元請の設定でGP34〜37%になるが、これは**元請側の粗利率**。光和の粗利とは別物

## 3. 見積書の様式（客先提出）

```
Ⅰ. 改修工事
   ├ 工種（解体／内装／設備／電気／…）
   │   ├ 明細行（数量 × 単位 × 単価）… 定価を併記
   │   └ 小計
   └ 工事費小計
   諸経費（工事費小計 × 10%）
   値引き（千円丸め）
   合計（税抜）／消費税／合計（税込）
```

- 🔴 **客先へはPDFで渡す**（Excelのまま渡すとO列の原価・Claude Log が漏れる）
- Excel列：**K=数量／L=単位／N=売単価×数量／O〜S=単価欄**（O列＝原価は印刷範囲外に置く）
- COM出力の必須設定：**工事名称A:F結合／単価列の幅を広げる／空行は非表示／FitToPagesTall**
- 印影オブジェクトを保持するため **Excel COM方式**で扱う。🔴 **社長がブックを開いている間は書かない**（別インスタンスで開くと破損する）

## 4. 元請別の返信スタイル（LIXIL）

| 担当者 | 出し方 |
|---|---|
| **佐藤保彦様** | 先方が見積を作る → **「予算的に◯◯円欲しい」とざっくり返す**（見積書は不要） |
| **鈴木優嘉様** | 数量を提示される → **数量×単価**で見積を作る |
| **嶋中様** | 単品を即答 |

## 5. 提出前の最終確認

- [ ] 数量の根拠を残したか（どの図面のどこから、どう計算したか）
- [ ] ⚠️ 不明・未確定の項目を明示したか（黙って0や仮値を入れていないか）
- [ ] 粗利率は25〜30%に収まっているか
- [ ] 客先版に原価が残っていないか（PDF化して確認）
- [ ] 支払い台帳（`デスクトップ\工事支払い一覧.xlsm`）へ業者別予算を反映したか
- [ ] 現場名は**邸名＋物件名を併記**したか（業者は住所・物件名、元請は邸名で来るため）
