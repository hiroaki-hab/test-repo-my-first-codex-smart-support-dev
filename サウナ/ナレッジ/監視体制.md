## 8. タスクスケジューラの正しい設定（実機で確立 / 2026-06-03）

### 症状（毎朝勝手に動かなかった原因）
- `前回の結果: -2147024703`（= `0x800700C1` = プログラムを起動できない）
- タスクの実行コマンドが `py C:\KowaBot\main.py` で、**`reconcile` 等のサブコマンドが抜けていた**
- かつ `ログオン モード: 対話型のみ` ＝ ログオフ中は走らない

### 🔔 正しい設定：.bat でラップする方式（これが安定）
1. 起動用batを作る（例：reconcile）
   ```
   echo @echo off> C:\KowaBot\run_reconcile.bat
   echo cd /d C:\KowaBot>> C:\KowaBot\run_reconcile.bat
   echo python main.py reconcile>> C:\KowaBot\run_reconcile.bat
   ```
2. **管理者cmd**でタスクを作り直す（`/it`＝パスワード不要・対話実行、`/f`＝上書き）
   ```
   schtasks /create /tn "KowaBot-Reconcile" /tr "C:\KowaBot\run_reconcile.bat" /sc hourly /st 19:55 /it /f
   ```

### トラブル対処（実機でハマった点）
- 「**実行者パスワードを入力**」「**アクセスが拒否されました**」
  → cmdが管理者でない。**管理者として実行**したcmdで `/create /f /it` する（`/it`でパスワード不要）
- 確認方法：
  ```
  schtasks /query /tn "KowaBot-Reconcile" /v /fo LIST | findstr /C:"前回の結果"
  findstr /C:"reconcile OK" C:\KowaBot\logs\YYYY-MM-DD.log
  ```
  `前回の結果: 0` ＋ ログに `=== End: reconcile OK ===` が出れば成功。

### 状態（2026-06-03 全タスク修正完了）
- ✅ サブコマンドは `keepalive` / `reconcile` / `cancel-watch`（`python main.py --help` で確認済み）
- ✅ **3タスクとも .bat 方式に作り直し、`前回の結果: 0` を確認**：
  - `run_reconcile.bat` → `schtasks /create /tn "KowaBot-Reconcile" /tr "C:\KowaBot\run_reconcile.bat" /sc hourly /st 19:55 /it /f`
  - `run_keepalive.bat` → `schtasks /create /tn "KowaBot-Keepalive" /tr "C:\KowaBot\run_keepalive.bat" /sc minute /mo 5 /it /f`
  - `run_cancelwatch.bat` → `schtasks /create /tn "KowaBot-CancelWatch" /tr "C:\KowaBot\run_cancelwatch.bat" /sc minute /mo 10 /it /f`
- ⚠️ **同名の古い壊れたタスクが残っていると、作り直したつもりでも古い設定が動く**
  → 必ず `/f` で上書きし、「**正しく作成されました**」が出ることを確認（`/run` の「実行が試行されました」は別物）
### 🔔 夜間運用は設定変更なしで24時間稼働(2026-06-03 ローカルClaudeが実機検証＋社長確認)
実機で裏取りした事実：
- ✅ **電源接続中はスリープ/休止しない**（`powercfg` AC設定 STANDBYIDLE/HIBERNATEIDLE とも `0x0`＝なし）
- ✅ **画面ロック中も「対話型のみ」タスクは動き続ける**（ロック≠サインアウト）
- ✅ 社長の運用は「**ロック or 付けっぱなし**（サインアウトしない）」と確認（2026-06-03）
- ⇒ **Windowsパスワード設定は不要**。現構成のまま24時間動く。

残る⚠️（パスワードなしでは完全には防げない）：
- **Windows Update の強制再起動・うっかりサインアウト/シャットダウン**が起きると、
  その間〜次回ログインまで止まる（「ログオンの有無に関わらず実行」に変えるには結局パスワードが要る）。
- アカウントは現在 `Password required: No`（空パスワード）。空パスワードは batch logon に使えないため、
  もし将来「ログオフ中も動かす」を選ぶなら**まずWindowsパスワード設定が前提**になる。
- 緩和策 ✅**導入済み(2026-06-03)**：**ログオン時に reconcile を1回自動実行**。
  再起動/サインアウトで空いた穴を、次回ログイン直後に自動で埋める保険。
  - Task Scheduler の `/sc onlogon` は**管理者権限を要求して拒否**されたため、
    **管理者不要のスタートアップフォルダ方式**を採用（機能は同等）。
  - 実体: `C:\KowaBot\run_reconcile_onlogon.bat`（ネット安定待ち30秒→`python main.py reconcile`）
    を、スタートアップの `KowaBot-ReconcileOnLogon.vbs`（WScript で**ウィンドウ非表示起動**）が呼ぶ。
  - スタートアップ場所: `…\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\`
  - ⚠️ `.bat`/`.vbs` はローカルPCのみ。リポジトリにはコミットしない（C:\KowaBot 配下は bot 本体扱い）。

### 🔔 cmd窓を出さない（2026-06-03 社長指示「作業中に窓が突然出て邪魔」）
- 原因：3タスクが `/it`（対話実行）で `run_*.bat` を直接起動 → reconcile時は約30秒コンソールが居座る
  （keepalive 5分毎・cancel-watch 10分毎も同様に窓を出していた）。
- 試した没案：`schtasks /change` で実行先を wscript に変更 → **「run as password」を要求**され停止
  （`/it`タスクの変更は資格情報の再入力が必要・空パスワードでは不可）。「仮想デスクトップ2に固定」も
  一瞬出る窓を狙って送るのは不安定で没。
- ✅ 採用：**各 `run_*.bat` を「`start "" wscript //nologo C:\KowaBot\hide_*.vbs`＋即終了」に書き換え**。
  wscript はコンソール無し → 窓が出ない。`hide_*.vbs` が `Run(cmd,0,True)` で python を非表示実行。
  - 生成物（ローカルのみ・非コミット）：`hide_reconcile.vbs` / `hide_keepalive.vbs` / `hide_cancelwatch.vbs`
  - 管理者・パスワード不要。タスクの実行先（run_*.bat）は変更不要なので資格情報プロンプトも出ない。
- ⚠️ **副作用：タスクの「前回の結果」は常に 0（撃ちっぱなし）になる**。bat が wscript を起動して即終了するため。
  → **成否は必ずログで確認**（`=== End: reconcile OK ===` 等）。「前回の結果: 0」は成功の証拠にならなくなった。
- ⚠️ **残る一瞬のチラつき**：タスクが bat を起動する瞬間だけコンソールが数十msだけ出る。完全ゼロにするには
  タスクの実行先を wscript 直呼びに変える必要があり、それには**管理者＋Windowsパスワード**が要る（未対応）。
- 🔔 **教訓（最重要）：`.bat` のコメントは必ず ASCII（英語）で書く**。cmd は .bat を cp932 で読むため、
  UTF-8 の日本語 `rem` コメントが文字化けして `'...' は認識されません` エラーになり、一瞬の窓にエラーが出る。
  日本語の説明は .vbs（wscript が許容）かこのドキュメント側に書く。
