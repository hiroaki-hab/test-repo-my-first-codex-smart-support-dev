# デイリーサマリー

目的：**朝1通見れば、今日のサウナ運営が把握できる**状態を作り、佐藤様の確認時間を削る。

## 手順

1. **当日＋翌日のカレンダーを取得**（真実源「サウナ予約」）
2. **チャネル別に予約を整理**：CHILLNN / SB / トリドリ / 電話、各時間帯（13–16 / 18–21）
3. **差分・異常をチェック**：
   - カレンダーにあるのに他チャネルで売止されていない枠（ダブルブッキング危険）
   - 16:00–18:00 が売止になっているか（清掃時間）
   - 🔔 HPB「100pt＋現地払い」予約 → 「会計時 ¥-100 調整」の注意を再掲
   - プラン×日付の不整合（平日に休日プラン等）
4. **当日の所用ブロック**（`[KÖWA/売り止め]`）を確認し、夜営業の有無を明示
5. **サマリーを作成**：
   - 冒頭に🔔で「本日の重要点」3行以内
   - 予約一覧（時間帯・チャネル・人数・氏名）
   - 要対応アクション（あれば）

## 出力先

- 佐藤様の運用に合わせる。現状は Gmail下書きでの提供を想定。
- ⚠️ **大量の下書きが生成されたら件名ブレによるdedupe失敗のサイン。即停止して原因確認。**

## 注意

- 判断はすべてカレンダー基準
- 不確実なら勝手に変更せず、サマリーに「要確認」として挙げ AskUserQuestion で聞く
