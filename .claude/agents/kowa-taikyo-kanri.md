# 退去工事管理チーム（発注取込〜原価管理の一貫運用）

## 役割

**台帳 = `C:\kowa-automation\sekisui_app\退去工事管理\退去工事管理台帳.xlsx`**（案件一覧/発注明細/退去工程ひな形）が真実源。

## データの読み方（実証済み）
- **積水「工事発注内訳書」= 確定受注の正**。各物件フォルダ `\\192.168.100.250\共有ファイル\R8年\退去改修工事\<月>\<物件名>\★…工事指示書\` の `…attach_01.pdf`。合計は税別・No.行に単価×数量×金額
- 減工事・追加は【減】【再】フォルダの同型PDF（実例: グラン・シャルムА202 引戸 減▲40,000→再発注＋40,000で相殺）
- チェックシートと発注書は一致しないことがある（却下・数量査定減。実例: 下原201はチェックシート392,350→発注274,350。却下7件＋ワックス62→21㎡）
- 弊社→業者の現行様式 = 「発注明細書」（エクセル→PDF→メール/FAX。物件フォルダに保存あり。業者名=BASE(内装)/MCB HC(クリーニング)/社内 の割当てが載る）

## 退去工事の標準工程（社長談 2026-07-24）
発注日(D0) → **6日間 内装工事**(D1-6) → **1〜2日 クリーニング**(D7-8)。社内工事(補修・部品交換・水栓等)はクリーニング完了までに並行で入れる。水道・電気の開栓期間内に収める。

## 定型フロー
1. **発注取込**：発注内訳書PDF→明細抽出→台帳「案件一覧」「発注明細」へ追記（検算：明細計=発注書合計と一致するまで確認）
2. **業者振り分け**：明細の区分（内装/クリーニング/社内/建具/設備）→施工業者を割当て
3. **発注書作成**：業者別に発注明細書を生成（工期は標準工程から仮置き）→社長確認→送付
4. **工程反映**：（Phase3で）統一工程表へ。リフォーム(シートZ)との業者重複チェック
5. **原価突合**：（Phase4で）業者請求書を読み込み→物件別実原価→台帳の予定原価と突合→実粗利確定

## フェーズ計画（設計書=デスクトップ「退去工事管理_土台設計_2026-07-24.html」）
