# 現場支配シートZ ⇄ 工程管理AI 連携手順（仮工程の自動反映）

> 工事メール → 秘書が検知 → 部長 → 工程管理AI が「仮工程」を起こし、
> **シートZの専用タブ「仮工程_受信」へ自動で1物件分を追記**する仕組み。
> ★メイン台帳（手書きの板）は絶対に触りません。安全に専用タブへ着地させます。

---

## 全体の流れ

```
LIXIL等の工事メール
   │  ① 秘書(kowa-hisho)が「工事ワード」で検知→TODO化
   ▼
 部長(メインセッション)  ② リフォーム工程と判断→工程管理へ
   │
   ▼
 工程管理(kowa-koutei)   ③ 仮工程JSONを生成（物件＋工程行＋業者＋工期(仮)）
   │  push_kari_koutei.py が Webhook へPOST
   ▼
 シートZ「仮工程_受信」タブ  ④ 1物件分を自動追記（状態＝仮（未反映））
   │
   ▼
 社長が確認 → メイン板へ手で昇格（=ここは人が最終判断）
```

## 初回セットアップ（1回だけ・社長作業）※完了済み・記録として残す

### A. Apps Script を貼る
1. 現場支配シートZ を開く →「拡張機能」→「Apps Script」
2. `現場支配シートZ_受け口.gs` の中身を全部貼り付けて保存

### B. 合言葉（シークレット）を設定
1. Apps Script 左の「⚙ プロジェクトの設定」→「スクリプト プロパティ」
2. プロパティ名 `KARI_KOUTEI_SECRET` ／ 値＝**好きな合言葉**（例：長めのランダム文字列）を追加して保存
   - ⚠️ この合言葉が、無断書き込みを防ぐ鍵です。他人に教えない。

### C. ウェブアプリとしてデプロイ
1. 右上「デプロイ」→「新しいデプロイ」→ 種類＝**ウェブアプリ**
2. 「次のユーザーとして実行」＝**自分**／「アクセスできるユーザー」＝**全員**
3. デプロイ → 表示された **ウェブアプリURL** をコピー
   - 初回は権限承認のダイアログが出る → 自分のGoogleで承認

### D. URLと合言葉をローカルに保存（コミット禁止）
このフォルダに `genba_z.secret.json` を作り、下記を保存：
```json
{ "url": "<コピーしたウェブアプリURL>", "secret": "<Bで決めた合言葉>" }
```
- このファイルは `.gitignore` 済み（GitHubに上がりません）。
- 動作確認：ブラウザでウェブアプリURLを開き `{"ok":true,...}` が出ればOK。

## 毎回の使い方（AI側・自動）

工程管理AIが仮工程JSONを作ったら、部長がこれを実行するだけ：
```
python リフォーム\工程管理\push_kari_koutei.py 仮工程_明石台石井様_2026-06.json
```
→ シートZの「仮工程_受信」タブに追記され、`[OK] …追加しました` と表示。

> ⚠️ デプロイ前（C・D未了）は、JSONは作れても送信できません。
> その間は工程管理AIが出す「貼れる表」を社長が手でメイン板に貼ってください。

## 仮工程JSONの形（工程管理AIが守る書式）

```json
{
  "bukken": { "name": "物件名", "address": "住所 or 確認中", "note": "備考(品番/範囲/出典等)" },
  "koutei": [
    { "kubun": "工種", "sagyou": "作業", "gyousha": "業者", "start": "yyyy/MM/dd", "end": "yyyy/MM/dd" }
  ],
  "source": "出典（メール件名/送信者）"
}
```
- `secret` はpushツールが自動で付けるのでJSONに書かない（合言葉の漏洩防止）。
- 業者の当てはめは過去台帳の最頻（クロス＝BLUE 等）。不明・推測は `note` に⚠️で明示。

---

## 安全・運用ルール（厳守）

- メイン台帳（手書きの板）には**自動で書かない**。着地は「仮工程_受信」タブのみ。
- 仮工程は**全部「仮（未反映）」状態**で入る。メイン反映＝社長の最終判断。
- 合言葉・ウェブアプリURLは**秘密**。リポジトリに置かない（ローカルのみ）。
- 住所・工期・業者が不明な所は埋めず⚠️で残す（推測で確定しない）。
