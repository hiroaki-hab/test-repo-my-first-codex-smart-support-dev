# 電気

## 1. まず契約容量と分電盤を見る

- 住宅は **単相3線式（100V/200V併用）** が標準。古い家は**単相2線式（100Vのみ）**＝200V機器が使えず**引込線・幹線の張替が必要**（🔴 数十万コース。見積前に必ず確認）
- **主幹ブレーカー容量**＝契約アンペア。30A/40A/50A/60A。東北電力へ変更申請（スマートメーターなら遠隔で変更可・工事不要のことが多い）
- **分電盤の空き回路数**を数える。空きが無ければ分電盤交換（13〜20回路のものへ）
- 🔴 **専用回路が必要な機器**（1機器1回路・他と共用不可）
  - IHクッキングヒーター … **200V・専用30A**（20Aでは足りない）
  - エコキュート … 200V専用
  - エアコン（特に200V） … 専用
  - 食器洗い乾燥機 … 100V専用15A
  - 電子レンジ・炊飯器の同時使用が多い所 … 100V専用推奨
  - 洗濯乾燥機（ヒートポンプ式） … 100V専用
  - 温水洗浄便座 … アース付コンセント

## 2. 回路と電線

| 電線 | 許容電流 | 分岐ブレーカー |
|---|--:|--:|
| VVF 1.6mm | 15A | 15A（1500W） |
| VVF 2.0mm | 20A | 20A（2000W） |
| VVF 2.6mm | 30A | 30A |

- 一般回路（照明・コンセント）は**1回路1500W目安**。1部屋1回路が理想
- 🔴 **水回り（洗面・キッチン・屋外）のコンセントはアース付＋漏電遮断器**。義務
- **屋外・浴室はIP規格の防水器具**

## 3. 住宅用火災警報器（退去改修の定番項目）

- **寝室と、寝室のある階の階段上部**に設置義務（仙台市条例で台所も推奨）
- 電池式10年寿命。**リチウム電池切れ＝本体交換**が実務
- 光和の受注単価：**5,500円/個（改正売価・原価3,300円）** → `sekisan` スキル参照

## 4. 24時間換気（2003年7月以降の建物は義務）

- 住宅は**0.5回/h**（1時間で室内空気の半分が入れ替わる）
- 🔴 **リフォームで気密を上げる（内窓・断熱）と、換気不足が結露・カビとして表面化する**。内窓を入れるときは給気口の確保をセットで見る
- 給気口を塞いでいる入居者が多い（寒いから）。指摘して開けてもらう

## 5. 資格・届出

- 電気工事士（第二種＝一般住宅／第一種＝500kW未満の事業用）
- **分電盤交換・幹線張替・引込は電力会社への申請**が伴う
- 光和の標準業者：**はやでん**／苦竹BASEのみ**タートル・コミュニケーションズ**（東杜シーテック側）

## 6. 現調チェック

- [ ] 単3か単2か（分電盤の主幹端子を見る）／契約A
- [ ] 分電盤の空き回路数・メーカー・製造年（20年超は交換推奨）
- [ ] 200V機器の予定（IH・エコキュート・エアコン）→ 専用回路の有無
- [ ] アース線の有無（水回り）
- [ ] 火災警報器の有無・製造年
- [ ] 引込線の状態（単2・碍子引きなら要更新）
