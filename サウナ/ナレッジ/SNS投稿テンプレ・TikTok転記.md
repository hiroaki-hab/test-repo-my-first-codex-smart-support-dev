# SNS投稿テンプレ ＆ TikTok 転記手順（手動の「型」）

> 社長指示 2026-06-03。Instagram の動画・リールを **TikTok へ転記（クロスポスト）** する手動運用の型。
> 前提：✅元ファイル（撮影した動画・透かし無し）あり / ✅IGはビジネス・クリエイター / まず手動で数本→型を磨く。
> ブランド軸は `SNS運用.md` の「発信の核」（＝**温度カスタム＝自在ととのい**・完全貸切・フレンドリー）。

---

## 0. 鉄則（伸ばすために絶対守る）

1. 🔔 **元ファイル（透かし無し）を使う。** IGからDLした透かし入り動画はTikTokで伸びにくい。
2. **縦型 9:16**。最初の **1〜2秒で掴む**（湯気・水しぶき・整い顔・温度計など"画"で）。
3. **音源はTikTok内のトレンド音**を選ぶ（元動画の音そのままより伸びやすい）。無音動画なら特に効く。
4. **キャプションは媒体ごとに微調整**（TikTokは話し言葉・短め＋ハッシュタグ多め、IGは世界観重視）。
5. **カバー画像**は温度や水しぶきが映える瞬間を選ぶ。

---

## 1. 投稿ステップ（TikTokアプリ・1本あたり）

1. 元動画をスマホに用意（PCにあるなら共有 or クラウド経由でスマホへ）
2. TikTokアプリ → ＋ → **アップロード** → 該当動画を選択
3. 必要なら **トレンド音源**を追加、テキスト/字幕（温度・プラン名など）を載せる
4. 下の**キャプション＋ハッシュタグ**を貼る（媒体に合わせて微調整）
5. **カバー**を選ぶ
6. 公開（または下書き保存で社長チェック後に公開）

---

## 2. キャプション テンプレ（コピペ用・フレンドリー／温度カスタム訴求）

**A. 温度自在を主役に**
```
サウナの温度も、水風呂の温度も、ぜんぶ自分好みに🔥🧊
KÖWA SAUNA は“自在ととのい”。今日はサウナ◯℃×水風呂◯℃でキメました😮‍💨
完全貸切だから、人目を気にせず自分だけのととのいを🛢️
ご予約はプロフィールから🔗
```

**B. 「あの組み合わせ」訴求**
```
「あの施設のサウナ温度と、ここの水風呂が最高なんだよな」
——その組み合わせ、KÖWA SAUNA なら全部ためせます🧖‍♀️
サウナ60〜110℃／水風呂3〜42℃まで自在にカスタム🔥🧊（カスタムは事前連絡）
仙台近郊・大和町の貸切バレルサウナ🛢️
```

**C. 完全貸切の気楽さ訴求**
```
完全貸切だから、サウナも水風呂もぜんぶ独り占め♨️
温度を自分好みにいじって、毎回ちがう"ととのい"を探す贅沢☁️
KÖWA SAUNA【貸切バレルで自在ととのい】
```

> 数字（◯℃）は実際の設定に置き換える。通常サウナ90-100℃／水風呂14-15℃、カスタム時は事前連絡。

## 3. ハッシュタグ セット（コピペ用）

**ブランド・ローカル**
```
#コーワサウナ #KOWASAUNA #貸切サウナ #バレルサウナ #仙台サウナ #宮城サウナ #大和町 #杜の丘
```
**強み・テーマ**
```
#自在ととのい #温度が選べるサウナ #ととのい #サウナー #水風呂 #サ活 #完全貸切
```
**TikTok拡散向け（数個ずつ織り交ぜる）**
```
#fyp #おすすめ #サウナ好きと繋がりたい #サウナ女子 #サウナ男子 #宮城観光
```

> 全部盛りにせず、1投稿あたり**ブランド3〜4＋強み3〜4＋拡散2〜3**くらいで組む。

---

## 4. 最初の数本の進め方（型を磨く）

1. まず **3本**を投稿（できれば「温度自在が伝わる」動画から）。
2. 48〜72時間後に **視聴維持率・いいね・保存・コメント**を確認。
3. 伸びたフック／効いたハッシュタグを採用、弱いものを差し替え → このテンプレを改訂。
4. 3本うまくいったら投稿頻度を決め、`SNS運用.md` に反映。安定したら `.claude/skills/` 化を検討。

---

## 5. この先の自動化（IGビジネス/クリエイターなので道はある）

- **予約投稿・分析**：Metricool 等で IG/TikTok をまとめて予約投稿＋数字管理（手動の型が固まってから）。
- **IG→TikTok 自動転記**：Repurpose.io 等（有料SaaS）/ または TikTok・IG 公式API で自前化。
  ⚠️ TikTok Content Posting API は**アプリ審査前は下書き投稿どまり**等の制約あり。まず手動で勝ち筋を掴んでから判断する。
