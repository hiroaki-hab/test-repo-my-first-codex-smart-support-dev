## 手順① 新規予約を検知したとき（CHILLNN / HPB / 電話 / トリドリ）

1. メール or 各管理画面で予約を検知する
2. Googleカレンダーに規約どおりのプレフィックス付きでイベントを作成
3. **他チャネルの該当時間帯を売止する（クロスロック）**
   - CHILLNN → `admin.chillnn.com/19c7a1b53493d2/items/plan/stock` で売止
   - SB → `salonboard.com/KLP/set/shiftSetup/?date=YYYYMM` でシフトに「予定あり」追加
4. スプレッドシート「KOWA_SAUNA_顧客情報」に追記
   （※Apps Script Webhookで自動追記される場合あり → `顧客管理.md`）

→ このフローは `.claude/skills/reservation-crosslock/` でスキル化済み

## 手順② キャンセルを検知したとき

1. CHILLNN / HPB からキャンセル通知メールを受信
2. カレンダーイベントを `[KÖWA/キャンセル] ◯◯さん` にリネーム、colorId=8（グレー）に変更
3. description の先頭に「⚠️ キャンセル済み（YYYY-MM-DD受付）」を追記
4. **他チャネルの売止を解除**（売止 → 販売中に戻す）

→ `.claude/skills/cancel-propagation/`

## 手順③ HPB予約の受付フロー（手動）

1. SB予約バーをクリック → 予約詳細ポップアップを開く
2. 「受付チェック」をクリック
3. 🔔 **利用ポイント計を必ず確認**：
   - 100pt使用＋現地支払い → 弊社会計時に **¥-100 円** 調整が必須
4. カレンダーイベントの description に⚠️警告を追記

## 手順④ 月初のSB「毎月の受付設定」

- 月初に**翌月の営業時間設定**を行う（これがないとシフト編集できない）
- URL: `https://salonboard.com/KLP/set/monthlySetup/`
- 一括入力で、平日staff×月–金・休日staff×土日 に **16:00–18:00 を全日「予定あり」** に設定

## キャンセルポリシー（対顧客・社長確認 2026-06-03）

- **CHILLNN にキャンセルポリシーを掲載済み**（公式予約サイト側で明示）。
- **当日の無断キャンセル（ノーショー）はキャンセル料を請求**する。
- ただし**体調不良など、理由により都度判断**（杓子定規にせず柔軟に対応）。
- ホテル業の標準ルールも参考にしつつ運用を検討中（今後ルールを明文化する余地あり）。
