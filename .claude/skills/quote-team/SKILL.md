# 見積チーム起動

引数(`args`)で渡された見積依頼を、以下の4ステップのパイプラインで処理する。引数がない場合は、まずユーザーに「何の見積か(対象・範囲・単価の指定有無)」を確認してから開始すること。

## 実行手順

各ステップは Agent ツールでサブエージェントを起動する。**前のステップの出力を必ず次のステップのプロンプトに全文含めること。**

1. **プランナー(quote-planner)**: 見積依頼を渡し、前提条件・WBS を作成させる
2. **工数見積担当(quote-estimator)**: ステップ1の WBS を渡し、三点見積で工数(人日)を算出させる
3. **価格算定担当(quote-pricer)**: ステップ2の工数表を渡し、見積書ドラフトを作成させる
4. **レビュー担当(quote-reviewer)**: ステップ1〜3の全成果物を渡し、抜け漏れ・検算チェックをさせる

## レビュー後の対応

- レビュー判定が「要修正」の場合: 重要度「高」の指摘は該当ステップのエージェントに差し戻して修正させ、再度レビューする(最大2回まで)。「中」「低」の指摘は最終報告に備考として残す
- レビュー判定が「承認」の場合: そのまま最終報告へ進む

## 最終報告

ユーザーへの最終メッセージには以下を含めること:

1. 見積書ドラフト(価格算定担当の出力、修正があれば修正後)
2. 工数見積の要約(合計人日・バッファ)
3. 不明点・要確認事項(プランナーが挙げたもの)
4. レビュー結果の要約

成果物をファイルとして残す指示があった場合は `quotes/` ディレクトリ配下に `YYYY-MM-DD-<件名>.md` として保存する。
