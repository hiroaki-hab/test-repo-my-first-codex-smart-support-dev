## 2. 営業フロー

### 2.1 基本フロー(助成金を使わない案件)

```
引合い → 現地調査 → 概算見積(第3章テンプレ) → 仕様確定・本見積 → 施工契約(第7章ひな形) → 着工 → 引渡し → 効果測定(第5章)
```

### 2.2 助成金活用案件のフロー(順序厳守)

```
①提案 → ②社労士紹介 → ③交付申請(顧客が社労士と実施) → ④交付決定(労働局) → ⑤施工契約 → ⑥着工 → ⑦支給申請 → ⑧助成金受給
```

| 段階 | 実施者 | 当社の役割 | 禁止事項 |
|---|---|---|---|
| ①提案 | 営業+小林(ウェルネス事業部) | 助成金の**情報提供**・概算見積の提示(参考見積として) | 「必ずもらえる」等の断定 |
| ②社労士紹介 | 営業 | 提携社労士の**紹介**まで | 申請書の作成・提出の代行 |
| ③交付申請 | **顧客と社労士** | 見積書・図面等の**資料準備の伴走** | 申請手続きの代行 |
| ④交付決定 | 労働局 | 待機。**この間に契約・着工しない** | 交付決定前の契約・着工・発注 |
| ⑤施工契約 | 顧客⇔当社 | 交付決定通知の**写しを確認してから**締結(第7章ひな形・助成金案件用特約を使用) | — |
| ⑥着工〜引渡し | 当社 | 交付決定内容と工事内容の齟齬がないか確認 | 交付決定と異なる仕様への無断変更 |
| ⑦支給申請 | 顧客と社労士 | 完了写真・領収書等の資料提供 | 代行 |

> **【営業資料・口頭説明の両方で必ず伝えること】**
> 「**労働局の交付決定前に施工契約を締結すると、その工事は助成対象外になります。**当社は交付決定の確認後にご契約をお願いしています。」
> この一文は、営業資料(第4章の1枚資料)・見積書の備考欄・商談時のトークの3箇所に必ず入れる。

### 2.3 交付決定前にできること/できないこと

| できる | できない |
|---|---|
| 現地調査・参考見積(「本見積・契約ではない」旨を明記) | 施工契約の締結・注文書の受領 |
| 助成金制度の一般的な情報提供 | 申請書の作成・提出代行(社労士独占業務) |
| 提携社労士の紹介、申請用の見積書・図面の提供 | 着工・資材発注 |
| 受給可能性の一般的な目安の説明(条件付き表現で) | 受給額・採択の確約 |

## 6. 施工事例化の型

引渡し時に顧客から**事例掲載同意書**(写真・数値の利用範囲を明記/たたき台につき顧問税理士・弁護士・社労士の確認要)を取得し、以下をワンセットで記録する。

| 記録項目 | 内容 | 取得タイミング |
|---|---|---|
| ビフォー写真 | 施工前のスペース(同アングルで撮影位置をマーキング) | 現地調査時 |
| アフター写真 | 完成後(同アングル)+利用シーン(社員の顔は同意がない限り写さない) | 引渡し時・3ヶ月後 |
| 工事概要 | パック種別・金額帯・工期・助成金活用の有無(「交付決定後に契約」の一文を事例にも記載) | 引渡し時 |
| 利用率 | 予約表・利用記録簿から月次利用回数/対象社員数(KÖWA SAUNA法人契約併用時は月次レポートが**税務3点セットの利用記録簿を兼ねる**) | 毎月 |
| 睡眠スコア | 施工前ベースライン vs 3ヶ月後(アンケート式: 睡眠偏差値・全国比較/デバイス式: 睡眠ステージ・いびき・寝姿勢・寝床内温度) | 施工前・3ヶ月後 |
| 顧客の声 | 経営者コメント(健康経営認定の「実感と自慢」につながった点) | 3ヶ月後 |
| 認定申請書用テンプレ | この事例を健康経営認定の申請書に書ける文言テンプレとして整形し、顧客に納品 | 3ヶ月後 |

**表現ルール(必須)**
- 「睡眠が改善する」「健康になる」等の**効果の断定表現は禁止**(健康増進法・景表法)。「当社事例では睡眠偏差値が○→○に変化しました(個人差があります)」等、実測値+個人差注記の形式で記載する。
- 睡眠スコアは個人が特定されない集計値のみ公開。個票データの社外公開は本人の書面同意がある場合に限る。
- 助成金活用事例では受給額を記載する場合、顧客同意+「年度・要件により異なります」の注記を付す。

## 7. 工事請負契約書ひな形(要点版)

> 【重要注記】本ひな形は**たたき台**であり、使用前に必ず**顧問税理士・弁護士・社労士の確認**を受けること。
> 建設業法19条は、建設工事の請負契約締結時に、法定記載事項を記した**書面の交付(または電磁的措置)**を義務付けている。35〜300万円の本パック工事はすべて建設工事請負契約に該当するため、口頭・注文書のみでの受注は行わない。

### 7.1 条文骨子(建設業法19条の法定記載事項に対応)

注文者 ____________(以下「甲」)と請負者 有限会社光和工業(以下「乙」)は、次のとおり工事請負契約を締結する。

| 条 | 見出し | 骨子 |
|---|---|---|
| 第1条 | 工事内容 | 工事名(仮眠室/サウナ施工工事・パック種別)・施工場所・仕様は、添付の本見積書・仕様書・図面(番号を明記)のとおりとする |
| 第2条 | 請負代金 | 請負代金額 金____円(**税別**)、消費税額 金____円、**税込合計 金____円**。税別・税込を必ず併記する |
| 第3条 | 工期 | 着工日 ____年__月__日/引渡日 ____年__月__日。天災・天候その他不可抗力による工期変更は甲乙協議のうえ書面で定める |
| 第4条 | 請負代金の支払時期・方法 | 例: 契約締結時に__%、引渡し完了時に残額を、乙指定の銀行口座への振込により支払う(振込手数料は甲負担) |

| 第6条 | 遅延損害金 | 乙の責による引渡遅延・甲の責による支払遅延について、それぞれ年__%(法定利率を目安に設定)の遅延損害金を定める |

### 7.2 助成金案件用の特約条項(たたき台)

> **特約(契約の効力発生条件)**
> 本契約は、甲が働き方改革推進支援助成金等に係る**労働局の交付決定通知を受け、乙がその写しを確認した日**に効力を生ずるものとする。交付決定が得られなかった場合、本契約はその効力を生じず、甲乙は互いに何らの債権債務も負わない。乙は、交付決定の確認前に着工・資材発注を行わない。

- 本特約は「交付決定後に契約・着工した工事のみが助成対象」という制度要件(第2章・第4章参照)を契約上担保するためのものである。
