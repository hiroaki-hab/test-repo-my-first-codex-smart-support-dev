# キャンセル伝播

キャンセルを検知したら、カレンダーを更新し、**塞いでいた枠を再び売れる状態に戻す**。

## 手順

1. **キャンセル通知を確認**：CHILLNN / HPB のメールまたは画面で、対象予約を特定
2. **カレンダーイベントを更新**：
   - 名前を `[KÖWA/キャンセル] ◯◯さん` にリネーム
   - 色を Graphite(8)（グレー）に変更
   - description 先頭に「⚠️ キャンセル済み（YYYY-MM-DD受付）」を追記
   - ※削除はしない（履歴を残す）
3. **他チャネルの売止を解除**（売止 → 販売中）：
   - CHILLNN: `admin.chillnn.com/19c7a1b53493d2/items/plan/stock`
   - SB: 該当シフトの「予定あり」を外す
4. **平日/休日プランの整合**を再確認（再販する枠が正しいプランか）
5. **16:00–18:00 は再販しない**（清掃時間。売止のまま維持）
6. 顧客情報シートの状態を「キャンセル」に更新（自動でなければ手動）

## 完了報告

🔔 で始め、「どの予約をキャンセル表示にし・どのチャネルの売止を解除したか」を報告。

## 注意

- 🔔 **CHILLNN受付期間外（受付終了済み）の枠を販売中に戻さない** → CHILLNNが拒否する
- SB側の売止解除は前任botでは未実装だった領域。手動確認を丁寧に
