# ② リース会社の比較観点（選定チェック）

> サウナ＝動産リース。賃貸への設置・撤去が絡むため、扱える会社か見極めが要る。まず2〜3社に相見積。

| 比較軸 | 見るポイント |
|---|---|
| **リース料率/総支払** | 月額・総額・残価設定。60回/48回での料率差 |
| **与信の通しやすさ** | 個人・個人事業主・法人で条件が変わる。富裕層個人の通しやすさ |
| **動産/特殊物件の可否** | サウナのような据置設備を扱えるか（断られる会社もある⚠️） |
| **中途解約・残価・撤去/引揚げ** | 短期解約時の精算、**撤去・搬出の費用と段取り**、所有権の所在 |
| **再リース/使い回し** | 状態良好品の再活用に対応できるか（木材再生で残価が残る前提） |
| **ベンダー登録のしやすさ** | 光和が販売店として提携しやすいか、申込フローの簡便さ |
| **保険・保証連携** | 動産総合保険・PL/施工保証との組み合わせ |

- **候補タイプ**（⚠️具体条件は各社へ直接確認）：
  - 信販/ショッピングクレジット系（オリコ/ジャックス/アプラス等）＝個人向け分割に強い
  - リース専業（動産リース）＝法人・事業者向けに強い
  - メーカー/商材提携リース＝サウナ商材で提携実績があれば最短
- **進め方**：①2〜3社に「サウナ(据置・賃貸設置・撤去あり)を扱えるか」を一次確認 → ②料率・与信・撤去対応で比較 → ③1社を主、1社を予備に。
