# 数量の拾い方（部位別）

## 換算の基本
- **1坪 = 3.3058㎡**／1帖(江戸間) ≒ 1.548㎡／1間 = 1,820mm／半間 = 910mm
- 壁の高さ：一般天井高2,400mm／マンション2,400〜2,500／和室2,300

## 内装

| 項目 | 拾い方 |
|---|---|
| **クロス** | 🔴 **床面積 × 3.3**（光和の標準式・壁＋天井を含む概算）。精密に出すなら「(部屋周長×天井高)＋床面積」から開口部を控除 |
| アクセントクロス | 対象壁の面積（幅×高さ）を実測 |
| **CF・フロアタイル・フローリング** | **床面積そのまま**。ロス見込みは単価側に含む |
| 狭所CF（玄関土間・トイレ・洗面所） | 🔴 **面積でなく「一式」固定**（単価表に式単価あり） |
| 巾木 | 部屋の**周長**（m）。出入口分を控除 |
| 見切り・framing | 箇所または m |
| 襖・障子・網戸 | 枚 |
| 畳 | 帖 |
| カーテンレール | m または本 |

## 塗装・外装

| 項目 | 拾い方 |
|---|---|
| **外壁塗装** | 実測が原則＝**(外周長 × 軒高) − 開口部**。概算は**延床面積 × 1.2〜1.4** |
| 屋根塗装・葺替 | **投影面積 × 勾配係数**（4寸=1.08／5寸=1.12／6寸=1.17／8寸=1.28） |
| **足場** | **掛面積 =（建物外周長 + 8m）× 軒高＋α**。「+8m」は四隅の振れ分 |
| 高圧洗浄 | 塗装面積と同じ |
| 雨樋 | 軒樋＝軒の長さ(m)／竪樋＝高さ×本数 |
| 破風・鼻隠し・軒天 | m または ㎡ |
| シーリング | **打ち替え＝目地の総延長(m)**。サッシまわり＋ボード目地を別々に拾う |

## 解体・産廃

- **解体は「部位×数量」で拾い、産廃は㎥（立米）で拾う**
- 産廃の目安：木造内装解体で**1坪あたり0.3〜0.5㎥**（中身により変動大）
- 混載の処分費は**18,000円/㎥**（コンクリート・タイル混は24,000円/㎥）※単価マスター
- 🔴 **2006年9月以前の建物はアスベスト事前調査費を必ず別途計上**（→ `kenchiku-chishiki/references/houki.md`）

## 住設・設備

- **原則「箇所」「台」で拾う**（UB1216＝1台、便器＝1台）
- 付帯を忘れない：**解体撤去／給排水切り回し／電気配線／大工造作（額縁・下地）／内装復旧／搬入費**
  - 🔴 「本体＋取付」だけの見積は必ず赤字になる。廣田邸の教訓＝**発注内訳の全項目を割り付ける**
- 給排水配管：**m**（給水・給湯・排水を別々に）＋継手・弁は式
- 電気：**回路数・器具数・配線m**。専用回路の要否は `kenchiku-chishiki/references/denki.md`

## 工数（歩掛）— 工期算定にも使う

| 作業 | 1人1日あたり |
|---|--:|
| **クロス張り** | **50㎡**（社長ルール・工程日数もこれで割る） |
| CF張り | 30〜40㎡ |
| フロアタイル | 20〜30㎡ |
| 床上張り（大工） | **約29坪で9稼働日**（佐藤巧様邸の実績） |
| 外部塗装（一式） | **3週間**（洗浄〜付帯まで／社長ルール） |
| 内装解体 | 2〜3坪 |

## 拾いの実務ルール

1. **図面から拾ったら、必ず現調の実測で照合**する（既存図と現物は違う）
2. **部屋ごとに表を作る**（部屋名／床㎡／クロス㎡／CF㎡／建具／付帯）。合計だけ書かない
3. 数量の**根拠（どの図面のどこから、どう計算したか）を残す**。後で必ず聞かれる
4. ⚠️ 拾えない部分は**空欄＋⚠️**にする。0や仮値を黙って入れない
