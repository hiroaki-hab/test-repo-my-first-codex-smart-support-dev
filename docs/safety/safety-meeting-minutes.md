## 1. 公衆災害の報告：駐車場からの飛び出しによる物損事故

本日発生した公衆災害（駐車場でのシフト操作ミスによる物損事故）について報告があった。
詳細は別紙の事故報告書を参照。

- 報告書: [公衆災害 事故報告書（駐車場での車両事故）](parking-accident-report.md)
- 要点
  - 人身被害はなかったが、歩行者・自転車が通る公道上での事故であり、重大事故になり得た。
  - 原因は運転者のシフト操作ミスの可能性が高いが、車両不具合の可能性も含め調査中。
  - 全員、運転は余裕を持ち、シフト位置の確認を徹底すること。

## 2. スライドドアに関する注意喚起

- 今回の敷地は、**水勾配がきつめ（厚め）の駐車場**という敷地形状であった。
- 傾斜があるため、**スライドドアの勢いが相当強くなっていた**とみられる。
- 傾斜地では、スライドドアの開閉時に手指の挟み込みや急な閉まり・開きが起こりやすいため、十分注意すること。

> この話題の前段部分は文字起こしに含まれていないため、スライドドアに関する具体的な事象（事故・ヒヤリハットの有無）は要確認。

## 3. 雨天時の敷地清掃中の転倒事故

| 項目 | 内容 |
| --- | --- |
| 状況 | 敷地の清掃（外周の掃き掃除）中、雨で足を滑らせて転倒した |
| 負傷 | 転倒時に身体を切る負傷があった（部位・程度は要確認） |
| 発生場所 | 駐車場内（つるつるした路面で滑った） |

> 文字起こしでは「首を切断」と記録されているが、音声認識の誤りの可能性が高い。負傷部位・程度は必ず確認すること。

### 注意事項

- 雨の日は路面が滑りやすい場所があるため、**雨天時の作業は十分注意**すること。
- **靴の摩耗具合**を確認すること。使っている本人は気づきにくいため、靴底がすり減って滑りやすくなっていないか、従業員への周知を改めて行う。
- 駐車場内のつるつるした路面は、**入居者の方も同じように転倒する可能性**がある。

### 滑りやすい箇所の報告依頼

- 各現場で作業中に「ここは滑る」と感じる箇所があれば、報告すること。
  - 依頼元（管理会社・オーナー等）の現場であれば、それぞれの依頼元へ連絡する。
  - 自社の現場作業であれば、会社（担当部署）まで連絡する。
- 報告があればその都度対応する。
