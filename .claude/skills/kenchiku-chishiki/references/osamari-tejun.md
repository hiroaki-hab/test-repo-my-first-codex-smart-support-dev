# 納まり・施工順序・納期

## 1. 工種の順序と「なぜその順か」

**原則：隠れるものが先／汚すものが先／仕上げは最後**

```
① 仮設（養生・仮設トイレ・電気水道）
② 解体・撤去          … 一番汚す。この後に他業者を入れない
③ 設備配管（給排水）  … 床下・壁内に隠れる。位置が決まらないと下地が組めない
④ 電気配線           … 同上。配管と干渉するので配管の後
⑤ 大工（下地・造作・建具枠） … 配管配線を隠す
⑥ 内装（クロス・床）  … 大工完了が絶対条件
⑦ 設備器具付け（便器・洗面・キッチン） … 内装後（先だと養生・破損リスク）
⑧ 電気器具付け（照明・スイッチ・コンセント） … 内装後
⑨ 美装クリーニング → 完了検査 → 引渡し
```

🔴 **やってはいけない前後（手戻りの実例）**
- クロス後に配線・配管の穴あけ → **クロス張り替え直し**
- 床仕上げ後に住設・重量物搬入 → **傷・へこみ**
- 建具枠の前に床上張り → **枠の見込みが足りず納まらない**
- 塗装（外部）の足場を解体してから雨樋・板金の不具合発覚 → **足場再設置**

## 2. 光和の標準工程型（詳細は `.claude/agents/kowa-koutei.md`）

- **住設入替の5日型**：①解体・切離し ②組立・接続 ③大工・内装 ④仕上げ ⑤清掃・引渡し
- **後工程を前工程に半日〜1日重ねる**と5日に収まる
- 工程日数の目安：**クロス1日50㎡**／外部塗装3週間／床上張り29坪で9稼働日
- **日曜・祝日・盆(8/13〜15)は稼働日に数えない**（土曜は稼働）

## 3. 🔴 材料納期（工程を決める前に押さえる）

| 品目 | 目安 |
|---|--:|
| 一般在庫のクロス・CF | 2〜5日 |
| 便器・洗面化粧台（標準品） | 1〜2週 |
| システムキッチン | 3〜4週 |
| ユニットバス | **4週前後** |
| 内窓（インプラス・標準色） | 2〜3週 |
| 玄関ドア（カバー工法） | **4〜6週** |
| 特注サッシ・特注色 | **6週〜** |
| 給湯器（品薄期） | 変動大・要都度確認 |

- 🔴 **「工事日を先に決めて、材料が間に合わない」が最も多い事故**。受注→即発注、または納期回答を得てから工程確定
- 住設の色・柄の**施主決定が遅れると納期が動く**。決定期限を工程表に明記して施主・元請に伝える（苦竹BASEの未確定4件が実例）

## 4. 気温・季節の制約

- **塗装**：5℃以下／湿度85%以上は不可（仙台の12〜3月は日中のみ・工期に余裕）
- **モルタル・コンクリート**：凍結の恐れがある時期は養生（練り混ぜ水の加温・シート養生）
- **シーリング**：低温時は硬化が遅い
- **クロス**：冬に暖房を効かせすぎると乾燥収縮でジョイントが開く
- **外構土間**：凍結深度以深の路盤・冬期はひび割れ注意

## 5. 居ながら（住みながら）工事の段取り

- **使用不可期間を先に伝える**：バス（解体日〜組立完了翌日）、トイレ、キッチン
- 代替手段を用意：仮設トイレ／近隣入浴施設の案内／簡易流し
- **1日の作業終了時に必ず使える状態に戻す**もの：玄関の施錠、給水、電気、トイレ
- 高齢者・小さい子・ペット・在宅勤務の有無を現調で聞く
- 近隣挨拶：**音・振動の出る日／車両が停まる日／足場設置期間**を明示（→ `リフォーム/工程管理/kinrin_annai.py`）

## 6. 引渡し前チェック（是正の出やすい所）

- [ ] 建具の開閉・戸当たり・チリ（床上張りで下端が擦っていないか）
- [ ] クロスのジョイント開き・入隅の切れ・見切り
- [ ] コーキングの通り・汚れ
- [ ] 通水試験（全器具）・漏水／排水の流れとゴボゴボ音（→ `kyuhaisui.md`）
- [ ] 通電・スイッチとの対応・照明の向き
- [ ] 換気扇の風量・給気口の開放
- [ ] 傷・へこみ（特に既存を残した部分は着工前写真と照合）
- [ ] 清掃（MCB）／残材・産廃の撤去完了
- [ ] 取扱説明書・保証書・鍵の引渡し

## 7. 写真の残し方（証拠が身を守る）

- **着工前**（既存の傷・汚れを必ず撮る＝後の「壊した」クレーム防止）
- **隠蔽前**（配管・配線・下地補強・断熱材＝後から見えない所は撮らないと証明できない）
- **完了**
- アスベスト調査の掲示・分別解体の状況も撮る（法令記録）
