# 予約クロスロック

新しい予約を検知したら、**ダブルブッキングを防ぐため**に全チャネルへ反映する。

## 前提

- 真実源は Googleカレンダー「サウナ予約」
  （ID: `4ff2159e052aef82de43575b0287e68803d76ca578f771c7f869d8cec0fce46f@group.calendar.google.com`）
- カレンダー命名規約・色は `サウナ/CLAUDE.md` 第3章
- SBのパスワードは入力しない（人間に再ログインを依頼）

## 手順

1. **予約内容を確認**：日付 / 時間帯（13–16 or 18–21）/ 人数 / 氏名 / チャネル
2. **平日・休日プランの整合を確認**（`サウナ/CLAUDE.md` 第4章）
   - 平日に休日プラン、土日祝に平日プランが入っていないか
3. **カレンダーにイベント作成**：プレフィックスと色を規約どおりに
   - CHILLNN → `[KÖWA] ◯◯さん (n名)` / Basil(10)
   - SB → `[SB] ◯◯さん (n名)` / Tangerine(6)
   - トリドリ → `[トリドリ] ◯◯ (n名)` / Grape(3)
   - 電話 → `[電話] ◯◯さん (n名)`
4. **他チャネルの同時間帯を売止**：
   - CHILLNN: `admin.chillnn.com/19c7a1b53493d2/items/plan/stock`
   - SB: `salonboard.com/KLP/set/shiftSetup/?date=YYYYMM` に「予定あり」追加
5. **16:00–18:00 が売止のままか確認**（清掃時間。常に塞ぐ）
6. **顧客情報シートへの記録**を確認（Apps Scriptが自動追記。漏れていれば手動追記）

## 完了報告

🔔 で始め、「どの予約を・どのチャネルに反映し・どこを売止したか」を1行で報告。
不確実な点（プラン整合・受付期間など）があれば AskUserQuestion で佐藤様に確認する。

## 注意

- CHILLNN受付期間内（今日＋1日）の枠は触らない
- 人間が手動入力した（プレフィックス無し）イベントは触らない
