# 「野心経営 × アンモチベーション」に類似する経営哲学・理論の調査レポート

作成日: 2026-07-15

## 1. 調査対象

対象URL: https://seminar.amj.ne.jp/p/OZUExpljQHob
(「野心経営×アンモチベーション 体験セミナー」ランディングページ)

ページ本文はほぼ全て画像で構成されているため、掲載画像33枚を取得して全文を書き起こした上で内容を分析した。

### 1.1 提唱者

- **青柳智大(あおやぎ ともひろ)氏** — AMJ株式会社 代表取締役
- 「ニューロリノベーション協会」設立、「自創経営 公式インストラクター」
- 自動車整備士 → 営業職 → 経営者という現場叩き上げの経歴。過労による体調不良を脳科学・心理学・NLP(神経言語プログラミング)の研究で克服した経験が思想的バックボーンと自称
- 自社AMJを年商8億円→43億円(約5.3倍)に成長させた実績を訴求

### 1.2 メソッドの中身(LPからの要約)

**(1) 野心経営(アンビジョナルプランニング)** — 経営者向け

- 「アンビジョン」= 野心・自我欲求(年収、ライフスタイル、手に入れたいもの等の本音)。「ビジョン」= 公の欲(社会貢献・顧客満足等)
- 教育によって自我欲求にリミッターがかかっており、ほとんどの経営者は「綺麗事のビジョン」しか持てていない、と主張
- アンビジョンの方がビジョンより目標達成力が強い。根拠として「報酬予測が鮮明になるとドーパミンが分泌され、それが動機になる」という脳科学的説明を用いる
- ただし野心むき出しでは周囲に悪影響があるため、**アンビジョンを核にして、その周りを公のビジョンでコーティングする「ダブルビジョン」**を作る
- ダブルビジョンの実現から逆算して中長期事業計画を策定する = アンビジョナルプランニング

**(2) アンモチベーション(コントロール)** — 社員マネジメント向け

- 社員の「やる気がない」は本人の資質・根性の問題ではなく、行動を阻む**「組織内の障害」**(代表的な10種類の組織的障害)と「脳のメカニズムに逆らった関わり方」が原因
- 脳がフリーズして行動が止まる瞬間を「アンモチベーション」「ダウンビジョン」と呼ぶ
- 上司は指示・命令ではなく**「質問」と「情報提供」**で部下の脳を刺激し、自ら解決策を見つけさせる(ドーパミン再分泌でモチベーションがV字回復すると説明)
- リーダーは「教える」から「気づかせる」へ。障害を取り除く**「支援型リーダーシップ」**を担い、心理的安全性の高いチームを作る(オキシトシン・セロトニンの語彙で説明)

## 2. 類似・同系統の経営哲学/理論

独自用語(アンビジョン、ダブルビジョン、アンモチベーション等)が使われているが、構成要素を分解すると、既存の理論・哲学と強く重なる。

### 2.1 「野心経営」に類似する考え方

| 類似の哲学/理論 | 提唱者 | 共通点 |
|---|---|---|
| 『非常識な成功法則』 | 神田昌典 | **最も直接的な類似**。「嫉妬・見栄・欲望などの"悪の感情"をエネルギーに変える」「綺麗事を捨てて金銭的欲望に正直になる」「目標を紙に書きアファメーション・ビジュアライゼーションで刷り込む」。"欲望を離陸の燃料にし、軌道に乗ったら心を磨く"という二段構えは「ダブルビジョン」と同じ発想構造 |
| 『思考は現実化する』 | ナポレオン・ヒル | この系譜の源流。「明確な願望(燃えるような願望)」を定め、達成した場面を鮮明にイメージし、自己暗示で潜在意識に刷り込む。野心発掘セッションの「何を本当に成し遂げたいか」はヒルの"明確な目標"の問いとほぼ同型 |
| ルー・タイス/苫米地英人系コーチング(TPIE・PX2) | Lou Tice、苫米地英人 | 「have-to(やるべき)ではなくwant-to(心から欲しい)のゴールを現状の外に設定する」「ゴール達成時の臨場感あるイメージが脳(RAS・スコトーマ)を書き換え行動を生む」。**脳科学の語彙で欲望駆動の目標設定を正当化する**点まで含めて構造が同じ |
| 『論語と算盤』 | 渋沢栄一 | 私利(算盤)と公益(論語)を両立させる。「私欲を核に公のビジョンで包むダブルビジョン」は、私益追求を大義で包んで社会に受容させる合本主義の構造と類似(順序は逆で、渋沢は道徳が主・利益が従) |
| ビジョナリーカンパニーの BHAG | ジム・コリンズ | 「社運を賭けた大胆で野心的な目標(Big Hairy Audacious Goal)」が組織を熱狂させ求心力を生む、という主張は「経営者の本気の野心が組織のエネルギー源になる」と同旨(ただしBHAGは会社の野心、野心経営は社長個人の野心) |

### 2.2 「アンモチベーション」に類似する考え方

| 類似の哲学/理論 | 提唱者 | 共通点 |
|---|---|---|
| 自己決定理論(SDT) | エドワード・デシ、リチャード・ライアン | **学術的に最も対応する理論**。やる気は個人の資質ではなく、自律性・有能感・関係性という心理的欲求を環境が満たすか損なうかで決まる。「外的統制(指示・命令・アメとムチ)が内発的動機を破壊する」という主張はアンモチベーションの核心と一致 |
| 『モチベーション3.0(Drive)』 | ダニエル・ピンク | SDTの経営向け普及版。「自律(Autonomy)・熟達(Mastery)・目的(Purpose)」が動機の源泉であり、管理型マネジメントは時代遅れ、とする点が同旨 |
| 二要因理論(動機づけ・衛生理論) | フレデリック・ハーズバーグ | 不満・やる気低下を生む「衛生要因」の除去と、やる気を生む「動機づけ要因」を分けて扱う。「10種類の組織的障害を特定して除去する」はまさに衛生要因アプローチ |
| X理論・Y理論 | ダグラス・マグレガー | Y理論=「人は本来自ら働き成長したがる。経営の仕事は命令・統制ではなく、それが発揮される条件整備」。「社員が勝手に動き出す」「障害を取り除く支援者」はY理論の現代版 |
| サーバントリーダーシップ | ロバート・グリーンリーフ | 「リーダーは支配者ではなく奉仕者・支援者」。LPの「支援型リーダーシップ」「障害を取り除く支援者」はほぼ同義 |
| コーチング/1on1(GROWモデル、ヤフーの1on1) | ジョン・ウィットモア、本間浩輔ほか | 「教えるのではなく質問で気づかせる」「答えは相手の中にある」。広告のターゲティング(utmパラメータ)にも「1on1面談」が含まれており、本セミナー自体が1on1・コーチング文脈で集客されている |
| 心理的安全性 | エイミー・エドモンドソン(Googleの「プロジェクト・アリストテレス」で普及) | 「失敗を恐れず挑戦できるチーム」の条件としてLPが明示的に採用している概念そのもの |
| ニューロリーダーシップ/SCARFモデル | デイビッド・ロック | **「脳科学×マネジメント」という枠組みの先行例**。地位・確実性・自律性・関係性・公平性への脅威が脳の脅威反応を起こしパフォーマンスを止める、という説明は「脳がフリーズするアンモチベーションの瞬間(ダウンビジョン)」とほぼ同型。著書『最高の脳で働く方法(Your Brain at Work)』、ドーパミン・オキシトシン等の語彙でリーダーシップを説明する点も共通 |

### 2.3 直接の系譜(本人が学んだ・認定を受けているもの)

- **自創経営(東川鷹年氏、株式会社自創経営センター)** — 青柳氏は「自創経営 公式インストラクター」を名乗っており、これが最も直接的なルーツ。自創経営は西尾レントオールの人事を33年務めた東川鷹年氏が体系化した「社員が自ら考え行動し、結果を出す」人材育成の仕組みで、「チャレンジシート」「ランクアップノート」「成長対話」といったツールで目標管理と自律性を育てる。「社員の自律」「対話による育成」という骨格はここから来ていると考えられる
- **日本経営合理化協会** — LPに「日本経営合理化協会では事業計画を学ぶ」と明記。中長期事業計画(アンビジョナルプランニングの計画部分)の技術的ベース
- **NLP(神経言語プログラミング)** — 本人がニューロリノベーションの構成要素として明言。ゴールの視覚化・言語化・リフレーミングなどの技法群

### 2.4 表面的に似ているが方向性が逆のもの(対比)

- **識学(安藤広大氏)** — 「モチベーションを上げる施策は無駄」という出発点は共通するが、結論が正反対。識学はルール・役割・位置の明確化による統制で解決し、モチベーションには介入しない。アンモチベーションは支援型リーダーシップと内発的動機で解決する。「モチベーション研修否定」つながりで混同されやすいが哲学は対極
- **稲盛和夫(利他の経営)・松下幸之助(水道哲学)** — 「動機善なりや、私心なかりしか」に代表される利他・大義先行の経営哲学。野心経営はこうした「綺麗事のビジョン」経営への意図的なカウンター(逆張り)として設計されており、思想的には対立軸にある

## 3. 総評

「野心経営×アンモチベーション」は完全に新規の哲学ではなく、次の4系統の組み合わせを独自用語で再パッケージしたものと整理できる。

1. **欲望駆動の目標設定(自己啓発系成功法則)** — ナポレオン・ヒル → 神田昌典・ルー・タイス系。「本音の欲望こそ最強の動機」「達成イメージの視覚化」
2. **内発的動機づけの経営理論(学術系)** — マグレガーY理論、ハーズバーグ、デシ&ライアンのSDT、ピンク『モチベーション3.0』。「やる気は環境が決める。障害を除去せよ」
3. **支援型の人材開発手法** — サーバントリーダーシップ、コーチング/1on1、心理的安全性、自創経営(直接の師事先)
4. **脳科学の語彙によるパッケージング** — ニューロリーダーシップ(SCARF)、NLP。ドーパミン・オキシトシン・セロトニンでの説明

留意点: 「アンビジョンはビジョンよりドーパミン分泌量の桁が違う」等のLP上の主張は、ドーパミンの報酬予測機能(神経科学のドーパミン報酬予測誤差研究)を下敷きにしたポピュラーサイエンス的な言い回しであり、その定量的な比較自体に学術的裏付けが示されているわけではない。学術的に確立しているのは2の系統(SDT、二要因理論等)であり、1と4は自己啓発・実務系の言説である点は区別して受け取るのが妥当。
