## 1. 社長の睡眠測定(1〜3万円)の商品仕様

### 1-1. 商品概要

| 項目 | 内容 |
|---|---|
| 商品名 | 社長の睡眠測定(経営者向けデバイス式睡眠測定) |
| 価格 | 1社あたり1〜3万円(税別)。測定人数・報告方法により見積り |
| 測定方式 | デバイス式:ブレインスリープ コイン(睡眠ステージ/いびき/寝姿勢/寝床内温度) |
| 測定期間 | 1〜2週間(推奨:平日+週末を含む連続7泊以上) |
| 対象 | 経営者・役員(健康経営のトップコミットメントの「実感」づくり) |
| 位置づけ | 運用の型「測って→施策→3ヶ月後再測定」の入口商品。**全社測定(第2章)とセットで全従業員に機会を開く設計を推奨** |
| 税務上の注意 | 役員のみを対象とする測定費用を会社負担とする場合、特定の役員のみが利益を受けるものとして**役員給与として課税される論点**がある(役員のみを対象とする人間ドック費用と同様の整理)。全社測定とセットにし、全従業員に機会を開く設計を推奨する。**本費用の税務処理(福利厚生費/役員給与)は顧問税理士にご確認ください** |

### 1-2. デバイス貸出フロー

| 手順 | 内容 | 担当/様式 |
|---|---|---|
| ①申込 | 申込書+測定同意書(第4章)に署名 | 小林 |
| ②貸出前点検 | 充電・アプリ動作・清拭消毒・シリアル番号記録 | 貸出台帳に記載 |
| ③貸出 | 対面で装着方法・アプリ設定を説明(15分)。貸出借用書に署名(紛失時取り決め含む) | 借用書 |

## 6. 表現ガイドライン(健康増進法・景表法)

### 6-1. 原則

1. **効果を断定しない。** 「治る・改善する・眠れるようになる」等の保証表現は口頭を含め全面禁止。
2. **事実は言ってよい。** 実施したこと・測定したこと・参加率・全国比較の数値は事実として記載できる。
3. **体験談は「個人の感想」と明示**し、効果の裏付けであるかのような見せ方をしない。
4. 認定申請書テンプレ・報告書・チラシ・SNS・体験会の口頭説明のすべてに適用。配布物は小林が事前に本ガイドラインで確認する。

### 6-2. 対照表

| 場面 | ❌ ダメな表現(断定・保証) | ⭕ 言ってよい表現(事実・可能性・提案) |
|---|---|---|
| 睡眠測定 | 「測定すれば睡眠の質が改善します」 | 「ご自身の睡眠の状態を数値で知ることができます」 |
| 睡眠偏差値 | 「偏差値が上がれば健康になれます」 | 「全国データと比較した現在地がわかります」 |
| サウナ | 「サウナで不眠が治ります」「疲労が回復します」 | 「リフレッシュの場としてご利用いただけます」「睡眠と休養をテーマにした福利厚生の選択肢です」 |
| セミナー | 「受講すれば生産性が◯%向上」 | 「睡眠と働き方に関する情報をお伝えします」 |
| ブレインスリープ製品 | 「この枕で深く眠れるようになります」 | 「メーカー公表の製品特長をご案内します」(公式表現の範囲内) |
| 施策全般 | 「離職率が下がります」「医療費が減ります」 | 「睡眠に取り組む企業の事例をご紹介します」「取組の一つとしてご検討いただけます」 |
| 再測定 | 「3ヶ月で必ず数値が良くなります」 | 「3ヶ月後に再測定し、変化を一緒に確認します」 |
| 体験談 | 「お客様全員が効果を実感」 | 「※個人の感想です。効果を保証するものではありません」を付記した個別の声 |
| 価格・優待 | 根拠のない「通常価格」からの割引表示 | 「契約企業の社員様は定価(メーカー希望小売価格)の80%」 |
| 認定 | 「当社サービスで認定が必ず取れます」 | 「認定取得・更新に向けた申請書類の準備を伴走支援します(成果報酬型)」 |
| 助成金 | 「助成金がもらえます」「申請を代行します」 | 「助成金の情報提供と社労士のご紹介、資料準備の伴走を行います(申請代行は社労士の独占業務)。交付決定前の施工契約は助成対象外となる点にご注意ください」 |

### 6-3. 医療・診断に関する線引き

| 禁止 | 代替 |
