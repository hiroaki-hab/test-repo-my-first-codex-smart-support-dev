## 中期（事業横展開）

> 「Coworkで動いた成功体験を他事業に展開したい」（佐藤様）。

| 拡張案 | 内容 | 構築方針 | 工数感 |
|---|---|---|---|
| **定期清掃の多人管理** | 光和工業の清掃業務。多人のスケジュール調整＋現地写真検証 | Python + Playwright + Claude Vision API | 2〜3hで土台 |
| **積水ハウス不動産システム連携** | 物件登録自動化、写真アップロード＋確認 | Playwrightで管理画面操作 | 4〜6h（解析含む） |
| **写真確認のAI判定** | Claude Vision APIで構造化判定（「①床にゴミ無い？②テーブル拭けてる？」をyes/no質問形式で） | Vision API | 3〜5h |
